# 간격에 차이를 주어, 관련 내용을 시각적으로 그룹핑합니다.

같은 섹션 안의 간격은 좁게, 서로 다른 섹션 사이의 간격은 넓게 설정합니다. 간격만으로도 어떤 내용이 서로 관련되어 있는지 구별할 수 있게 합니다.

- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/basics/space/

> 제목과 본문, 표와 설명처럼 함께 읽어야 할 요소를 가까이 배치합니다. 구분선이나 배경색을 더하기 전에 간격으로 섹션이 구분되는지 확인합니다.

## 먼저 지킬 원칙

- **제목은 뒤따르는 본문에 붙이기** 제목 위 간격과 아래 간격을 똑같이 두면 어느 문단의 제목인지 모호해질 수 있습니다.
- **자료와 설명을 함께 두기** 표의 단위·집계 조건을 해당 표 가까이에 둡니다. 페이지 끝에 모아 두면 어떤 자료의 조건인지 다시 찾아야 합니다.
- **간격 종류를 적게 정해 반복하기** 문단 안, 같은 주제 안, 다른 주제 사이의 간격을 구분합니다. 고정 모듈을 맞추려고 문장을 임의로 멀리 떼지 않습니다.

## 배치로 비교하기

같은 문장에서 제목 앞뒤 간격만 바꾸면 제목과 본문의 관계가 어떻게 달라지나요?

글자 크기·폭·원고와 전체 간격 합계는 같습니다. B에서는 제목이 뒤의 설명에 더 가까워집니다. 수치는 이 화면의 비교 조건입니다.

## 적용할 때 살펴볼 것

소제목이 중간에 들어가는 본문에 적용합니다. 이미 문단 번호나 구분선으로 섹션을 구분했다면 간격을 과하게 더하지 않습니다.

## 내 문서에서 확인하기

- 제목이 어느 본문에 속하는지 분명한가요?
- 자료와 단위·출처가 서로 가까운가요?
- 같은 의미의 간격이 페이지마다 반복되나요?
