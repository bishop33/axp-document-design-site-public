그리드로 배치 기준을 정하고, 내용에 맞게 공간을 나눕니다.

여백·열·행·거터로 내용을 배치할 자리를 정합니다. 같은 그리드에서도 여러 칸을 합치면 본문·표·차트를 다르게 배치할 수 있습니다.

기본 원칙 03그리드와 정렬
본문이 1단이라고 바탕 그리드도 한 칸인 것은 아닙니다. 큰 요소의 위치를 정하는 모듈 그리드와 본문 글줄을 맞추는 baseline grid를 구분합니다. 빨간 안내선은 실제 배치에 사용한 기준을 보여줍니다.

먼저 지킬 원칙

여백과 내용 영역 정하기

머리글·본문·쪽번호의 영역을 정합니다. 안쪽과 바깥쪽 여백은 제본과 판형을 고려해 조정합니다.

열·행·거터로 배치 기준 만들기

여러 칸을 합쳐 긴 본문이나 큰 표를 놓습니다. 칸마다 내용을 채울 필요는 없습니다.

baseline은 별도로 다루기

모듈은 큰 요소의 위치와 크기, baseline은 본문 글줄의 높이를 맞춥니다. 표와 차트의 모든 선을 본문 기준선에 억지로 맞추지 않습니다.

배치로 비교하기

같은 2열×2행에서 같은 내용을 어떻게 병합할 수 있나요?

같은 원고와 2열×2행을 사용했습니다. A는 위쪽 두 칸, B는 왼쪽 두 칸을 병합합니다. 빨간 선은 실제 배치에 쓴 행·열과 거터입니다. 이 모듈은 본문 baseline을 나타내지 않습니다.

직접 만든 학습 예시이며 수치는 가상입니다. 실물 인쇄·독자 시험을 거쳐 확정한 기준은 아닙니다.

적용할 때 살펴볼 것

비슷한 정보가 반복되는 내지에서 공통 기준으로 씁니다. 지면마다 필요한 표·그림의 크기가 다르면 병합 범위를 바꿉니다.
