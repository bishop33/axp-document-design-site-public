# 글자를 읽기 편하게, 크기·읽기 폭·행간을 함께 정합니다.

같은 글자 크기라도 한 줄의 길이와 줄 사이 간격에 따라 읽기 편한 정도가 달라집니다. 세 가지를 함께 조절해 글줄을 자연스럽게 따라 읽을 수 있게 합니다.

- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/basics/type/

> 기본 서체는 Pretendard입니다. 웹 안내는 화면에서, 인쇄 문서는 실제 판형에서, 발표 자료는 관람 거리에서 확인합니다. 아래 예시는 크기와 폭을 고정하고 행간의 차이를 비교합니다.

## 먼저 지킬 원칙

- **서체와 실제 판형부터 고정하기** 웹 안내는 화면에서 읽는 크기로, 인쇄 본문은 실제 pt와 판형으로 확인합니다. 화면 확대율만으로 인쇄 크기를 판단하지 않습니다.
- **한 번에 하나씩 바꿔 보기** 크기와 폭을 고정하고 행간을 비교합니다. 다음에는 행간을 고정하고 폭을 바꿉니다. 여러 값을 동시에 바꾸면 차이의 원인을 알기 어렵습니다.
- **한글·숫자·문장부호를 함께 확인하기** 닫는 괄호가 줄 첫머리에 남거나 숫자와 단위가 어색하게 갈라지는지 봅니다. 한글·영문의 눈에 보이는 아래 끝과 baseline은 같지 않습니다.

## 배치로 비교하기

같은 크기와 폭에서 행간만 바꾸면 글줄 사이가 어떻게 달라지나요?

두 예시는 Pretendard 16px, 같은 열 폭입니다. B는 글줄 사이 빈 공간과 문단 높이가 늘어납니다. 28px이 항상 정답은 아니며 실제 읽기 폭과 정보량에 맞춰 고릅니다.

## 적용할 때 살펴볼 것

긴 본문을 조정할 때 씁니다. 표의 숫자나 짧은 차트 라벨에 본문 행간을 그대로 적용하지 않습니다.

## 내 문서에서 확인하기

- 실제 인쇄 크기나 발표 거리에서 읽히나요?
- 긴 줄에서 다음 줄의 시작을 놓치지 않나요?
- 괄호·단위·줄 끝의 한두 글자가 어색하지 않나요?
