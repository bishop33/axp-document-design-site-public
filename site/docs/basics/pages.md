# 여러 페이지에서도, 일관된 배치와 읽는 흐름을 유지합니다.

제목·머리글·쪽번호는 같은 위치에, 함께 읽을 내용은 같은 페이지에 배치합니다. 페이지가 바뀌어도 내용을 이어 읽을 수 있게 합니다.

- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/basics/pages/

> 본문과 표의 양에 따라 페이지를 나누되, 소제목만 앞쪽 끝에 남거나 표의 열 제목이 사라지지 않게 확인합니다. 최종 PDF에서는 서체·줄바꿈·표 분할·여백을 다시 점검합니다.

## 먼저 지킬 원칙

- **공통 위치를 먼저 고정하기** 장 제목, 머리글, 쪽번호 위치를 반복합니다. 글 중심 쪽과 표 중심 쪽이 달라도 독자가 현재 위치를 찾을 수 있게 합니다.
- **페이지 끝에서 의미가 끊기지 않게 하기** 소제목만 앞쪽 끝에 남기지 않습니다. 다음 쪽 표에는 열 제목과 단위를 반복하고, 주석이 어느 표에 속하는지 표시합니다.
- **내보낸 파일로 다시 확인하기** HTML 화면이 정상이어도 PDF에서 서체·줄바꿈·표 분할이 달라질 수 있습니다. PDF 판형과 폰트, 실제 인쇄물의 여백과 제본을 확인합니다.

## 배치로 비교하기

같은 제목과 문단을 페이지 경계에서 어떻게 묶어야 하나요?

원고는 같고 페이지를 나누는 위치만 다릅니다. B에서는 제목과 해당 본문이 같은 쪽에서 시작합니다. 위 그림은 페이지 경계를 설명하는 도식이며 실제 출력 결과가 아닙니다.

## 적용할 때 살펴볼 것

인쇄·정독용 연속 내지에 적용합니다. 의도적인 장 구분 페이지는 별도로 설계하며, 모든 제목을 기계적으로 다음 쪽으로 넘기지 않습니다.

## 내 문서에서 확인하기

- 제목만 쪽 끝에 남아 있지 않나요?
- 이어지는 표에 열 제목·단위가 있나요?
- PDF와 실물에서 폰트·여백·재단·제본을 확인했나요?
