기본 원칙 01정보의 순서와 위계
독자가 내려야 할 판단을 먼저 정하고, 그 판단을 돕는 정보를 순서대로 배치합니다. 같은 단계의 제목은 같은 형식을 쓰고, 내용을 이해하는 데 꼭 필요한 조건은 가까이에 표시합니다.

먼저 지킬 원칙

정보 순서를 먼저 정하기

핵심 질문 → 판단에 필요한 근거 → 집계 조건과 출처를 연결합니다. 모든 문서가 결론부터 시작해야 하는 것은 아닙니다.

역할마다 강조를 다르게 하기

제목은 주제를, 본문은 이유를, 주석은 조건을 설명합니다. 크기·굵기·간격을 한꺼번에 늘리기보다 필요한 차이만 줍니다.

같은 역할은 같은 모양 유지하기

같은 단계의 소제목은 같은 크기와 간격을 씁니다. 문장마다 굵게 표시하면 강조가 서로 경쟁합니다.

배치로 비교하기

제목·본문·출처의 크기만 달라져도 역할을 구별할 수 있나요?

A는 제목·본문·출처의 글자 크기가 같습니다. B는 제목을 크게, 본문은 읽기 편한 크기로, 출처는 본문보다 작게 배치했습니다. 크기에 차이를 주면 각 글이 어떤 역할인지 구별할 수 있습니다.

직접 만든 학습 예시이며 수치는 가상입니다. 실물 인쇄·독자 시험을 거쳐 확정한 기준은 아닙니다.

적용할 때 살펴볼 것

내용을 이해하는 데 꼭 필요한 조건은 작게 처리하지 않습니다. 예를 들어 “매출 30% 증가”의 “전년 동기 대비”는 무엇과 비교한 수치인지 알려주는 정보입니다. 해당 수치 가까이에 읽기 쉬운 크기로 표시합니다.
