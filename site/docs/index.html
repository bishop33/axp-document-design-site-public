문서 디자인 가이드

기업 보고서와 발표 자료를 만들 때 쓰는 기본 원칙, 그리드, 차트, 실제 문서 레퍼런스와 제작 시험을 한곳에 모았습니다.

    인쇄용과 발표용 · 정보의 순서와 위계 · 서체와 조판 · 그리드와 정렬 · 간격과 그룹핑 · 표·차트·도식 · 연속 페이지와 출력

    레이아웃

    차트

    차트 원칙과 갤러리

  4. 04

    견본과 예시

    같은 내용을 표, 문장, 차트, 구조로 보여 준 견본.

    정보 표현 견본집 · 다이어그램 설명 실험

  5. 05

    레퍼런스

    실제 PDF·문서에서 추출한 내지 미리보기와 분석.

    실제 문서 레퍼런스

    문서 제작

    문서 유형별 제작과 검수 기록.

    투자검토 IM · 기술제안서 · 산업분석

    팀과 기록
