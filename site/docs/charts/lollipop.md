# 롤리팝

지점별 만족도 점수는 어떻게 다른가요?

- 분류: 크기 비교
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/lollipop/

## 예시 메시지

고객 만족도는 A 지점이 가장 높습니다. A 지점이 86점으로 가장 높고 E 지점은 61점입니다.

## 이럴 때 사용합니다

항목이 많아 막대가 무거워 보일 때 같은 비교를 가볍게 보여줍니다.

## 다른 표현이 나을 때

값의 차이가 작아 점끼리 겹치면 표가 낫습니다.

## 표현할 때 지킬 기준

- 막대와 마찬가지로 0에서 시작합니다.
- 값 순서로 정렬합니다.
- 선은 가늘고 옅게, 점과 라벨이 읽히게 합니다.

## 예시 데이터 · 지점별 만족도 (100점)

| 항목 | 지점별 만족도 (100점) |
|---|---|
| A 지점 | 86 |
| B 지점 | 79 |
| C 지점 | 74 |
| D 지점 | 70 |
| E 지점 | 66 |
| F 지점 | 61 |
