# 불릿(목표 대비)

각 지표는 목표를 얼마나 달성했나요?

- 분류: 크기 비교
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/bullet/

## 예시 메시지

4개 지표 중 2개가 목표를 넘었습니다. 매출과 신규 고객은 목표를 넘었고 이익률과 재구매율은 못 미쳤습니다.

## 이럴 때 사용합니다

실적과 목표를 한 줄에 함께 보여줄 때. 게이지 대신 씁니다.

## 다른 표현이 나을 때

목표가 없는 지표에는 쓰지 않습니다.

## 표현할 때 지킬 기준

- 목표는 세로 눈금 하나로 표시합니다.
- 달성한 지표만 강조색으로 칠합니다.
- 단위가 다른 지표는 달성률(%)로 맞춰 한 축에 둡니다.

## 예시 데이터 · 지표별 달성률 (%)

| 항목 | 실적 | 목표 |
|---|---|---|
| 매출 | 92 | 85 |
| 신규 고객 | 88 | 80 |
| 영업이익률 | 64 | 75 |
| 재구매율 | 71 | 80 |
