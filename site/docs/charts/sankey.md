# 흐름(생키)

고객은 어떤 경로로 유입되어 어디로 이어지나요?

- 분류: 증감 요인
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/sankey/

## 예시 메시지

유입 고객의 31%가 유료로 전환됩니다. 검색 유입 5,400명 가운데 1,900명이 유료 전환됐습니다.

## 이럴 때 사용합니다

출발과 도착이 있는 양의 흐름(유입 경로, 자금 흐름, 에너지 흐름)을 보여줄 때.

## 다른 표현이 나을 때

단계가 넷 이상이거나 선이 많이 겹치면 표나 퍼널로 나눕니다.

## 표현할 때 지킬 기준

- 선 굵기는 양에 비례합니다.
- 말하려는 경로 하나만 색을 씁니다.
- 단계 이름과 합계를 양 끝에 적습니다.

## 예시 데이터 · 고객 유입과 전환 (명)

| 출발 | 도착 | 값 |
|---|---|---|
| 검색 | 무료 가입 | 5400 |
| 광고 | 무료 가입 | 3100 |
| 추천 | 무료 가입 | 1500 |
| 무료 가입 | 유료 전환 | 3100 |
| 무료 가입 | 이탈 | 6900 |
