# 히스토그램

거래 금액은 어떤 구간에 몰려 있나요?

- 분류: 관계와 분포
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/histogram/

## 예시 메시지

거래의 절반이 1억–3억원 구간입니다. 1억–2억원 구간이 34건으로 가장 많습니다.

## 이럴 때 사용합니다

하나의 수치가 어떻게 분포하는지(치우침, 몰림, 긴 꼬리) 보여줄 때.

## 다른 표현이 나을 때

구간 폭을 바꾸면 모양이 달라집니다. 구간 기준을 주석에 적습니다.

## 표현할 때 지킬 기준

- 막대 사이 간격을 거의 두지 않습니다.
- 구간 폭을 같게 둡니다.
- 평균만으로 설명하지 않고 분포를 함께 봅니다.

## 예시 데이터 · 거래 금액 구간별 건수 (건)

| 항목 | 거래 금액 구간별 건수 (건) |
|---|---|
| ~1억 | 18 |
| 1–2억 | 34 |
| 2–3억 | 22 |
| 3–4억 | 11 |
| 4–5억 | 6 |
| 5억~ | 4 |

학습 예시 · 가상 데이터. 근거: https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/
