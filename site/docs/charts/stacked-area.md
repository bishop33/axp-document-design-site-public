# 누적 영역

전체 문의량과 채널별 구성이 어떻게 변했나요?

- 분류: 시간과 변화
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/stacked-area/

## 예시 메시지

문의가 100건에서 170건으로 늘었습니다. 전체 문의는 100건에서 170건으로 증가했습니다.

## 이럴 때 사용합니다

시간에 따른 전체 규모와 그 안의 구성 변화를 함께 보여줄 때.

## 다른 표현이 나을 때

각 채널의 정확한 변화량 비교가 중요하면 공통 기준선을 쓰는 별도 선 차트로 나눕니다.

## 표현할 때 지킬 기준

- 같은 단위로 합산 가능한 값만 누적합니다.
- 아래 영역을 제외하면 시작 높이가 달라 직접 크기 비교가 어렵다는 점을 고려합니다.

## 예시 데이터 · 분기별 문의량 (건)

| 항목 | 이메일 | 채팅 |
|---|---|---|
| 1분기 | 60 | 40 |
| 2분기 | 70 | 50 |
| 3분기 | 80 | 60 |
| 4분기 | 90 | 80 |

학습 예시 · 가상 데이터. 근거: https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/
