# 가로 막대

어느 제품의 매출이 가장 큰가요?

- 분류: 크기 비교
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/bar/

## 예시 메시지

제품 A가 매출 42백만원으로 가장 큽니다. 제품 A의 매출이 42백만원으로 가장 큽니다.

## 이럴 때 사용합니다

항목별 크기와 순위를 비교할 때. 항목 이름이 길어도 배치하기 좋습니다.

## 다른 표현이 나을 때

시점별 흐름이 중요하면 선 차트도 검토합니다.

## 표현할 때 지킬 기준

- 길이 비교가 왜곡되지 않도록 0에서 시작합니다.
- 순위가 질문이면 값 순서로 정렬합니다.

## 예시 데이터 · 제품별 매출 (백만원)

| 항목 | 백만원 |
|---|---|
| 제품 A | 42 |
| 제품 B | 36 |
| 제품 C | 28 |
| 제품 D | 18 |
