# 항목 비교표

두 서비스의 제공 조건은 어떻게 다른가요?

- 분류: 표
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/table-matrix/

## 예시 메시지

팀 요금제는 사용자 수와 공유 범위를 늘립니다. 팀 요금제는 사용자 20명과 공유 권한을 제공합니다.

## 이럴 때 사용합니다

서비스·제품·대안의 조건을 같은 기준으로 비교할 때.

## 다른 표현이 나을 때

각 열에 긴 설명이 필요하면 핵심 차이만 표에 남기고 설명을 분리합니다.

## 표현할 때 지킬 기준

- 비교 대상은 열에, 공통 비교 항목은 행에 배치합니다.
- 제공 여부는 글자로 명시합니다. 미제공과 미확인은 구분합니다.

## 예시 데이터

| 비교 항목 | 기본 | 팀 |
|---|---|---|
| 사용자 수 | 5명 | 20명 |
| 저장 공간 | 10GB | 100GB |
| 공유 권한 | 미제공 | 제공 |
| 월 요금 | 3만원 | 9만원 |
