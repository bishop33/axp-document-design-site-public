# 퍼널

각 단계에서 고객은 얼마나 남나요?

- 분류: 증감 요인
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/funnel/

## 예시 메시지

상담 신청 고객의 18%가 계약합니다. 방문 12,000명 가운데 계약은 380명이며 상담→견적 단계의 이탈이 가장 큽니다.

## 이럴 때 사용합니다

순서가 정해진 단계에서 남는 양과 단계별 전환율을 보여줄 때.

## 다른 표현이 나을 때

단계 순서가 없거나 앞 단계를 건너뛸 수 있으면 막대로 보여줍니다.

## 표현할 때 지킬 기준

- 단계마다 값과 앞 단계 대비 전환율을 적습니다.
- 폭은 값에 비례하게 둡니다.
- 가장 큰 이탈 단계를 본문 메시지로 씁니다.

## 예시 데이터 · 영업 단계별 고객 수 (명)

| 항목 | 영업 단계별 고객 수 (명) |
|---|---|
| 방문 | 12000 |
| 상담 신청 | 2100 |
| 견적 | 760 |
| 계약 | 380 |
