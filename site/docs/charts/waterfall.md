# 워터폴

시작 금액에서 최종 금액까지 무엇이 달라졌나요?

- 분류: 증감 요인
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/waterfall/

## 예시 메시지

증감 요인을 반영한 매출은 136백만원입니다. 매출은 신규·추가 구매와 이탈을 반영해 100에서 136백만원이 됐습니다.

## 이럴 때 사용합니다

시작값에 증가·감소 요인이 누적되어 최종값이 되는 구조를 설명할 때.

## 다른 표현이 나을 때

요인을 더해도 최종값이 되지 않으면 워터폴로 연결하지 않습니다.

## 표현할 때 지킬 기준

- 증가·감소에는 부호를 표시합니다.
- 시작과 최종 막대는 0에서, 변화 막대는 앞선 누적값에서 이어집니다.

## 예시 데이터 · 매출 증감 요인 (백만원)

| 항목 | 백만원 |
|---|---|
| 시작 | 100 |
| 신규 | 30 |
| 이탈 | -12 |
| 추가 구매 | 18 |
| 최종 | 136 |
