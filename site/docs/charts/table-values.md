# 수치 조회표

각 항목의 정확한 값은 얼마인가요?

- 분류: 표
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/table-values/

## 예시 메시지

매출과 영업이익은 4분기에 가장 큽니다. 2분기 매출은 120백만원, 영업이익은 18백만원입니다.

## 이럴 때 사용합니다

여러 지표의 정확한 값을 찾아보는 보고서와 검토 자료.

## 다른 표현이 나을 때

전체 흐름을 한눈에 보여줘야 한다면 필요한 지표를 차트로 분리합니다.

## 표현할 때 지킬 기준

- 숫자는 오른쪽에 정렬하고 같은 열의 소수 자릿수를 통일합니다.
- 단위는 열 제목에 표시하고 서로 다른 단위의 값을 합산하지 않습니다.

## 예시 데이터

| 분기 | 매출 (백만원) | 영업이익 (백만원) |
|---|---|---|
| 1분기 | 100 | 12 |
| 2분기 | 120 | 18 |
| 3분기 | 115 | 16 |
| 4분기 | 140 | 24 |
