증감 요인을 반영한 매출은 136백만원입니다

매출 증감 요인 (백만원)

매출은 신규·추가 구매와 이탈을 반영해 100에서 136백만원이 됐습니다.

학습 예시 · 가상 데이터

이럴 때 사용합니다

시작값에 증가·감소 요인이 누적되어 최종값이 되는 구조를 설명할 때.

다른 표현이 나을 때

요인을 더해도 최종값이 되지 않으면 워터폴로 연결하지 않습니다.

표현할 때 지킬 기준

  • 증가·감소에는 부호를 표시합니다.
  • 시작과 최종 막대는 0에서, 변화 막대는 앞선 누적값에서 이어집니다.

문서에 적용할 때

인쇄용은 실제 판형에서 숫자와 주석을 확인합니다. 발표용은 뒤쪽에서도 라벨이 읽히는지 확인하고, 필요하면 항목 수를 줄입니다. 이 화면의 글자 크기를 그대로 복사하지 않습니다.
