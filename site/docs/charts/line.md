# 선

응답시간이 분기마다 어떻게 달라졌나요?

- 분류: 시간과 변화
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/line/

## 예시 메시지

첫 응답시간이 2.2시간 줄었습니다. 첫 응답시간은 1분기 6.4시간에서 4분기 4.2시간으로 줄었습니다.

## 이럴 때 사용합니다

시간에 따른 변화 방향과 변동을 볼 때.

## 다른 표현이 나을 때

시간 순서가 없는 제품·부서를 선으로 연결하지 않습니다.

## 표현할 때 지킬 기준

- 시간 순서와 간격을 지킵니다.
- 빠진 기간의 값을 0으로 바꾸거나 임의로 연결하지 않습니다.

## 예시 데이터 · 분기별 평균 첫 응답시간 (시간)

| 항목 | 시간 |
|---|---|
| 1분기 | 6.4 |
| 2분기 | 5.8 |
| 3분기 | 4.9 |
| 4분기 | 4.2 |
