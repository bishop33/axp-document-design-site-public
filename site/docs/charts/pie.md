# 파이

전체 문의 중 각 유형은 얼마나 차지하나요?

- 분류: 구성비
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/pie/

## 예시 메시지

문의의 절반은 이용 방법에 관한 내용입니다. 이용 방법 문의가 전체의 절반입니다.

## 이럴 때 사용합니다

소수 항목으로 구성된 전체와 부분의 관계를 보여줄 때.

## 다른 표현이 나을 때

비중 차이가 작거나 항목이 많으면 막대가 비교하기 좋습니다.

## 표현할 때 지킬 기준

- 항목이 서로 겹치지 않고 전체 합계가 100%인지 확인합니다.
- 항목 이름과 비율을 조각 가까이에 표시합니다.

## 예시 데이터 · 4분기 문의 유형별 비중 (전체 100%)

| 항목 | 비중 (%) |
|---|---|
| 이용 방법 | 50 |
| 계정 | 30 |
| 결제 | 20 |
