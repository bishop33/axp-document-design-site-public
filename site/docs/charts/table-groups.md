# 그룹·소계표

항목별 금액과 그룹별 합계는 얼마인가요?

- 분류: 표
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/table-groups/

## 예시 메시지

국내 매출이 전체의 60%를 차지합니다. 국내 매출은 120백만원, 해외 매출은 80백만원입니다.

## 이럴 때 사용합니다

지역·사업부·제품군처럼 상위 분류와 하위 항목을 함께 조회할 때.

## 다른 표현이 나을 때

분류 단계가 많아지면 표를 나누고 하위 표로 연결합니다.

## 표현할 때 지킬 기준

- 그룹 안에서 세부 항목 다음에 소계를 배치합니다.
- 총계와 소계를 구분해 이중으로 합산하지 않습니다.

## 예시 데이터

| 구분 | 항목 | 매출 (백만원) |
|---|---|---|
| 국내 | 직접 판매 | 80 |
| 국내 | 파트너 판매 | 40 |
| 국내 | 소계 | 120 |
| 해외 | 직접 판매 | 50 |
| 해외 | 파트너 판매 | 30 |
| 해외 | 소계 | 80 |
| 전체 | 총계 | 200 |
