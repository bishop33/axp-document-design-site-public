# 100% 누적 막대

채널마다 해결 상태의 비중이 어떻게 다른가요?

- 분류: 구성비
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/stacked-percent/

## 예시 메시지

채팅의 해결 완료 비중이 15%p 높습니다. 해결 완료 비중은 이메일 70%, 채팅 85%입니다.

## 이럴 때 사용합니다

크기가 다른 집단의 구성비를 같은 전체 길이에서 비교할 때.

## 다른 표현이 나을 때

총건수 차이는 길이에 나타나지 않습니다. 규모가 중요하면 총건수도 함께 표시합니다.

## 표현할 때 지킬 기준

- 각 막대의 합계는 100%로 맞춥니다.
- 여러 구간을 넣기보다 독자가 비교할 핵심 비중을 정합니다.

## 예시 데이터 · 채널별 문의 처리 상태 (%)

| 항목 | 완료 | 진행 중 |
|---|---|---|
| 이메일 | 70 | 30 |
| 채팅 | 85 | 15 |
