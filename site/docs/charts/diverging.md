# 양방향 막대

부문별 이익은 전년보다 얼마나 늘거나 줄었나요?

- 분류: 증감 요인
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/diverging/

## 예시 메시지

7개 부문 중 3개 부문의 이익이 줄었습니다. 플랫폼 부문이 +18억원으로 가장 많이 늘었고 유통 부문은 -9억원입니다.

## 이럴 때 사용합니다

증가와 감소가 섞인 변화량을 기준선 양쪽으로 보여줄 때.

## 다른 표현이 나을 때

모두 같은 방향이면 일반 막대가 낫습니다.

## 표현할 때 지킬 기준

- 기준선(0)을 뚜렷하게 둡니다.
- 증가와 감소를 색이나 명도로 구분하되 빨강·초록 조합에만 의존하지 않습니다.
- 값에 부호를 붙입니다.

## 예시 데이터 · 부문별 영업이익 증감 (억원)

| 항목 | 부문별 영업이익 증감 (억원) |
|---|---|
| 플랫폼 | 18 |
| 데이터 | 11 |
| 컨설팅 | 6 |
| 교육 | 2 |
| 하드웨어 | -3 |
| 광고 | -5 |
| 유통 | -9 |
