# 묶은 막대

제품별로 두 해의 매출이 얼마나 다른가요?

- 분류: 크기 비교
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/charts/grouped-bar/

## 예시 메시지

제품 A의 매출 증가 폭이 가장 큽니다. 제품 A는 30에서 42백만원으로 증가했습니다.

## 이럴 때 사용합니다

같은 항목에서 두세 집단이나 시점을 직접 비교할 때.

## 다른 표현이 나을 때

집단이 많으면 막대가 빽빽해집니다. 소형 차트로 나누거나 비교할 집단을 줄입니다.

## 표현할 때 지킬 기준

- 각 항목에서 집단 순서를 유지합니다.
- 같은 척도를 사용하고 범례를 차트 가까이에 배치합니다.

## 예시 데이터 · 제품별 연간 매출 (백만원)

| 항목 | 2025년 | 2026년 |
|---|---|---|
| 제품 A | 30 | 42 |
| 제품 B | 32 | 36 |
| 제품 C | 20 | 28 |
