## 쪽마다 답할 질문과 표현

| 쪽 | 답할 질문 | 표현 |
|---|---|---|
| 요약 | 이 시장의 핵심 변화 세 가지는? | [KPI + 작은 추세](/docs/charts/sparkline/) |
| 시장 정의 | 어디까지를 이 시장으로 보나? | [시장 범위](/docs/diagrams/market-sizing/), 포함·제외 표 |
| 시장 규모와 전망 | 얼마나 크고 얼마나 빨리 크나? | [실적과 전망](/docs/charts/forecast/), [세로 막대](/docs/charts/column/) |
| 산업 구조 | 가치는 어느 단계에서 만들어지나? | [산업 지도](/docs/diagrams/value-chain/), [흐름(생키)](/docs/charts/sankey/) |
| 세부 시장 | 어느 세부 시장이 매력적인가? | [트리맵](/docs/charts/treemap/), [버블](/docs/charts/bubble/) |
| 경쟁 구도 | 누가 얼마나 차지하고 어떻게 변하나? | [포지셔닝 맵](/docs/diagrams/positioning/), [강조 선](/docs/charts/multi-line/) |
| 주요 기업 비교 | 기업별 규모와 수익성은? | [항목 비교표](/docs/charts/table-matrix/), [지수화 선](/docs/charts/indexed/) |
| 동인과 위험 | 무엇이 시장을 밀고 막나? | [양방향 막대](/docs/charts/diverging/), [이슈 트리](/docs/diagrams/issue-tree/) |
| 전망과 판단 | 그래서 어디에 기회가 있나? | 판단 표(기회 · 조건 · 신호) |

## 지킬 것

- 시장 정의를 가장 앞에 둡니다. 정의가 바뀌면 모든 수치가 바뀝니다.
- 시장 규모는 출처마다 다릅니다. 출처와 산정 방식을 수치 옆에 적고 출처를 섞지 않습니다.
- 경쟁사 비교는 같은 기준 연도·같은 회계 기준으로 맞춥니다.
- 전망 쪽은 가정과 반대 시나리오를 함께 둡니다.
