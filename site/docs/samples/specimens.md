# 같은 내용도 표현에 따라 다르게 읽힙니다

같은 내용을 표, 문장, 차트, 도식으로 바꿔 놓고 무엇이 먼저 읽히는지 비교합니다. 분류 일곱 개 중 하나를 고르세요.

- 상태: 검토 중
- 갱신: 2026-10-01
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/

- [텍스트·에디터](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/text/): 2종 — 제목과 문장의 위계, 에디터의 기본 구성요소
- [테이블](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/table/): 5종 — 표의 기본 골격, 다단 구조와 재무 비교, 그룹과 반복, 체크리스트, 근거와 해설, 선택안, 면의 농도로 계층을 구분합니다
- [차트](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/chart/): 4종 — 크기와 구성을 비교합니다, 시간과 증감의 흐름, 비중, 패턴, 관계, 분포와 목표, 연결
- [그룹핑](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/layout/): 1종 — 같은 내용을 묶는 네 가지 방법
- [구조·관계·플로우](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/structure/): 3종 — 소속과 거래는 다릅니다, 흐름에는 주체와 조건이 있습니다, 시간축과 운영 계층
- [체크리스트·Q&A](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/review/): 2종 — 무엇을, 왜 더 확인해야 합니까?, 기업 파악을 위한 추가 확인사항
- [한 장 요약](https://bishop33.github.io/axp-document-design-site-public/docs/samples/specimens/summary/): 2종 — 기업분석 한 장 요약, 기업을 한 장으로 읽습니다
