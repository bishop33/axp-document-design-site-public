# 관계와 구조는 도식으로 보여줍니다

누가 누구와 어떤 관계입니까? 이 질문에 답하는 도식 5종입니다. 하나를 누르면 쓸 때와 지킬 규칙을 볼 수 있습니다.

- 상태: 작성 중
- 갱신: 2026-09-30
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/diagrams/by-question/structure/

- [사업 구조도](https://bishop33.github.io/axp-document-design-site-public/docs/diagrams/business-model.md): 이 회사는 누구에게서 사서, 누구에게 팔고, 돈은 어떻게 들어오나요?
- [매출 구성 트리](https://bishop33.github.io/axp-document-design-site-public/docs/diagrams/revenue-tree.md): 매출은 어떤 사업과 제품에서 나오나요?
- [조직도](https://bishop33.github.io/axp-document-design-site-public/docs/diagrams/org-chart.md): 조직은 어떻게 나뉘고 각 조직에 몇 명이 있나요?
- [지배구조·지분도](https://bishop33.github.io/axp-document-design-site-public/docs/diagrams/ownership.md): 누가 이 회사를 소유하고, 이 회사는 어떤 회사를 소유하나요?
- [투자 구조도](https://bishop33.github.io/axp-document-design-site-public/docs/diagrams/deal-structure.md): 투자금은 어떤 경로로 들어가고, 거래 후 지분은 어떻게 바뀌나요?

예시는 모두 가상 기업과 가상 수치입니다.
