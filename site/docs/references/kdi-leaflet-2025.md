## 원본 내지

- PDF 2쪽 / 인쇄 표기 없음쪽: 펼침면 안에 기관 소개와 건물 사진, 연구 분야·센터의 방사형 도식, 발간물 사진과 종류 설명을 구분한다. 한 PDF 지면에 여러 패널이 들어 있으며 표지 목업이 아니라 내용이 인쇄된 펼침면이다. (https://bishop33.github.io/axp-document-design-site-public/references/assets/pdf-kdi-leaflet-2025-2.png)

## 관찰한 편집 방식

- 기관의 정체성·연구 영역·발간물을 서로 다른 내용 영역으로 보여 준다.

## 확인 범위와 한계

- 여러 접지 패널을 포함한 한 면을 일반 보고서의 한 쪽과 동일하게 비교하지 않는다. 정확한 접지 방향·제작 사양은 확인하지 않았다.
- 방사형 도식의 회전 글자와 작은 라벨을 분석 보고서에 그대로 이식하지 않는다.

## 예시에 적용할 실험

자체 제안: 기업 소개 예시에서 기관 목적·사업 영역·산출물의 내용 역할을 분리하는 데 참고하며 방사형 도식 자체를 권장하지 않는다.

원본의 저작권은 해당 권리자에게 있습니다. 실제 문서 21종의 내지 미리보기를 기본 목록에 표시합니다. 링크·템플릿·목업 후보는 탐색 후보로 분리했습니다. 기존 보유 PDF의 추가 지면 확인이며 이번 신규 웹 수집은 0건입니다. 미리보기 확보와 디자인 검수·사용자 채택은 별개입니다.
