## 검토할 항목

- 기존 개별 상품 제목·공식 소개 URL 기록. 유료 제작 파일 확보/실행 미확인. 판형·방향·서체 변형은 개별 상품이나 동일 계열이므로 독립 레이아웃 수 아님. 이번 전달은 텍스트 출처후보이며 로컬 preview 미연결.

## 확인 범위와 한계

- 후보 확보는 디자인 품질 승인이나 원본 제작 파일 확인을 뜻하지 않습니다.
- 현재 원문 URL의 접속과 재배포 권한은 별도 확인이 필요합니다.

검토 후보이며 원본 내지·제작 파일·세부 조판을 검증한 자료가 아닙니다.

## 예시에 적용할 실험

Bishop의 시각 선별 후 적용할 편집 원리를 분석합니다.

원본의 저작권은 해당 권리자에게 있습니다. 실제 문서 21종의 내지 미리보기를 기본 목록에 표시합니다. 링크·템플릿·목업 후보는 탐색 후보로 분리했습니다. 기존 보유 PDF의 추가 지면 확인이며 이번 신규 웹 수집은 0건입니다. 미리보기 확보와 디자인 검수·사용자 채택은 별개입니다.
