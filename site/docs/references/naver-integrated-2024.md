- 연속 지면에서 수치 개요와 사업 해설을 분담한다.

## 확인 범위와 한계

- 가로 PDF라는 이유만으로 회의실 발표에 적합하다고 볼 수 없다. 작은 연혁 글자는 확대가 필요하다.
