Single Column: 1단 본문 + 6개 모듈

공식 Features에는 6개 모듈, 선택형 여백/캡션 그리드, baseline grid, proportional leading이 명시돼 있습니다. 1단은 글의 배열이며 모듈 그리드와 반대되는 종류가 아닙니다.

첫 애니메이션에서 본문 옆 보조 영역과 여러 가로 구획을 관찰했습니다. 아래의 표·인용문 예시는 같은 시스템 안에서 요소의 크기와 배치가 달라집니다. 정확한 여백과 본문 pt는 공개 이미지로 확정하지 않았습니다.

Two Column: 2단 본문 + 12개 모듈

공식 사양은 12개 모듈, 선택형 여백/캡션 그리드, 11pt baseline grid입니다. 11pt는 본문 폰트 크기라는 뜻이 아닙니다. 모듈은 이미지·표의 자리와 크기를, baseline은 글줄의 높이를 정하는 서로 다른 기준입니다.

Swiss: 36개 모듈로 만드는 여러 배치

A4 판형, 36개 모듈, baseline grid와 10개 예시가 공식 사양입니다. 모듈 수가 본문의 단 수나 반드시 채울 상자 수를 뜻하지 않습니다. 필요한 폭과 높이만큼 병합하고 빈 공간도 남깁니다.

Digital Presentation: 화면용이라는 조건도 다시 봅니다

24개 모듈과 15pt baseline grid가 명시된 InDesign용 시스템입니다. 개인 화면에서 보는 디지털 문서와 회의실에서 투사하는 발표는 조건이 다릅니다. 원본의 baseline 수치를 발표용 본문 크기로 가져오지 않습니다.

이 가이드에서 바꾼 판단

이전의 큰 사각형 하나로 표현한 1단 예시는 상세 구조를 설명하기에 부족했습니다. 자체 예시를 2열×3행의 바탕 위에 본문이 2열을 합쳐 쓰는 형태로 다시 만들고, 실제 글줄 기준선을 별도로 표시했습니다. 이는 Kelman 제작 파일의 복제가 아닙니다.

원본의 본문이 지면에 비해 작고 조밀하게 놓인 점은 관찰할 수 있지만, 정확한 본문 크기는 미확인입니다. Pretendard 9·10·11pt 비교는 자체 시험이며 원본 사양이나 확정 권장값이 아닙니다. 유료 InDesign 파일·실물 인쇄·독자 시험은 확인하지 않았습니다.
