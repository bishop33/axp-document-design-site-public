# 대안을 견주고 순서를 보여주는 쪽의 그리드입니다

지면 역할 비교·절차·일정의 그리드입니다. 그리드 유형과 매체로 좁혀 볼 수 있고, 하나를 누르면 치수와 적용 예시를 봅니다.

- 상태: 검토 중
- 갱신: 2026-10-01
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/by-role/compare/

- [가로 항목 대조](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/landscape-comparison.md): 공유 항목을 기준으로 복수 대상의 정보를 같은 행에서 대조하는 가로 인쇄 시스템입니다. (모듈형 · 비교 · 인쇄용)
- [절차와 검증 대응](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/process-and-evidence.md): 절차의 선후 관계와 단계별 산출물·검증 조건을 같은 위치에서 연결하는 시스템입니다. (모듈형 · 절차·일정 · 인쇄용)
- [발표 대등 비교](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/slide-paired-evidence.md): 같은 질문에 대한 두 근거를 동일한 크기와 기준으로 대조하는 발표용 시스템입니다. (칼럼형 · 비교 · 발표용)
- [단계와 일정](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/slide-timeline.md): 네 단계를 왼쪽에서 오른쪽으로 놓고 아래에 일정·담당을 표로 받치는 발표 화면입니다. (모듈형 · 절차·일정 · 발표용)
- [대안 셋 비교](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/slide-three-options.md): 대안 세 개를 같은 폭의 열로 나누고 같은 항목 순서로 설명한 뒤 권고를 전폭으로 두는 발표 화면입니다. (칼럼형 · 비교 · 발표용)
- [대칭 표 비교](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-paired-tables.md): 두 대안·두 시나리오를 같은 구조의 표로 나란히 비교합니다. (칼럼형 · 비교 · 발표용)
- [비교 매트릭스 쪽](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-comparison-matrix.md): 경쟁사·대안·제품을 같은 항목으로 비교할 때 씁니다. (모듈형 · 비교 · 인쇄용)
- [대안 셋 카드 쪽](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-three-cards.md): 세 대안의 구조와 조건을 같은 순서로 비교하고 권고를 둘 때 씁니다. (칼럼형 · 비교 · 인쇄용)
- [단계와 일정 쪽](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-timeline-page.md): 기술제안서·실행 계획에서 단계와 일정, 산출물을 함께 보여줄 때 씁니다. (로우형 · 절차·일정 · 인쇄용)
- [절차 셋과 검증 쪽](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-process-steps.md): 업무·공정 절차와 단계별 검증 기준을 한 쪽에 둘 때 씁니다. (칼럼형 · 절차·일정 · 인쇄용)
- [단계 넷(발표)](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-process.md): 실행 단계를 네 개로 나눠 산출물과 함께 보여줄 때 씁니다. (칼럼형 · 절차·일정 · 발표용)
- [비교표(발표)](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-matrix.md): 대상 셋 이하를 항목 다섯 이하로 비교할 때 씁니다. (원고형 · 비교 · 발표용)
