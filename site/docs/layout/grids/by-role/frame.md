# 문서를 열고 나누고 닫는 쪽의 그리드입니다

지면 역할 표지·목차·섹션·마감의 그리드입니다. 그리드 유형과 매체로 좁혀 볼 수 있고, 하나를 누르면 치수와 적용 예시를 봅니다.

- 상태: 검토 중
- 갱신: 2026-10-01
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/by-role/frame/

- [섹션 표지](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/slide-section-divider.md): 섹션 번호와 제목을 크게 두고 이 섹션에서 답할 질문만 짧게 보여 주는 전환 화면입니다. (계층형 · 섹션 · 발표용)
- [검은 타이포 표지](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-cover-dark-type.md): 기업현황 보고서·IM 표지처럼 요소가 적고 첫인상을 강하게 만들 때 씁니다. (계층형 · 표지 · 인쇄용)
- [분할 표지](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-cover-split.md): 표지에서 문서 구성을 함께 보여 줄 때 씁니다. (모듈형 · 표지 · 인쇄용)
- [번호 목록형 목차](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-contents-numbered.md): 장이 5–10개인 보고서의 목차입니다. (칼럼형 · 목차 · 인쇄용)
- [검은 면 + 목차](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-contents-dark-split.md): 견본 펼침면의 "왼쪽 검은 쪽 + 오른쪽 목차"를 단면 A4 한 쪽으로 줄인 형태입니다. (칼럼형 · 목차 · 인쇄용)
- [번호 섹션면](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-section-numbered.md): 이미지 없이 여백과 큰 번호로 장을 나눌 때 씁니다. (계층형 · 섹션 · 인쇄용)
- [핵심 진술 + 목차면](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-section-statement-contents.md): 장 도입에서 요지와 문서 안 위치를 함께 보여 줄 때 씁니다. (칼럼형 · 섹션 · 인쇄용)
- [이미지 섹션면](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-section-image-band.md): 현장 사진·제품 사진이 있는 브로슈어나 기술제안서의 장 구분에 씁니다. (로우형 · 섹션 · 인쇄용)
- [마감면](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-closing-dark.md): 표지 요소를 줄여 반복하는 뒤표지입니다. (계층형 · 마감 · 인쇄용)
- [분할 표지(발표)](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-cover-split.md): 발표 첫 화면에서 제목과 구성을 함께 보여 줍니다. (칼럼형 · 표지 · 발표용)
- [번호 목차(발표)](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-contents.md): 장이 4–8개인 발표의 목차 화면입니다. (칼럼형 · 목차 · 발표용)
- [이미지 섹션 화면](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-section-band.md): 사진이 있는 발표의 장 전환 화면입니다. (로우형 · 섹션 · 발표용)
- [출처·주석 쪽](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-sources.md): 문서 끝에 출처와 주석을 모을 때 씁니다. (원고형 · 마감 · 인쇄용)
- [목차(발표, 좌 제목)](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-agenda.md): 발표 앞에서 장을 다섯 개 이하로 보여줄 때 씁니다. (칼럼형 · 목차 · 발표용)
- [마감(발표)](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-closing.md): 발표를 마치며 한 문장과 연락처만 남길 때 씁니다. (계층형 · 마감 · 발표용)
