# 글과 이미지를 읽히는 쪽의 그리드입니다

지면 역할 본문·본문과 이미지·인물의 그리드입니다. 그리드 유형과 매체로 좁혀 볼 수 있고, 하나를 누르면 치수와 적용 예시를 봅니다.

- 상태: 검토 중
- 갱신: 2026-10-01
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/by-role/body/

- [연속 본문](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/continuous-text.md): 한 줄기의 논증을 이어 읽으며 표와 그림은 본문 흐름에 삽입하는 시스템입니다. (원고형 · 본문 · 인쇄용)
- [대칭 2단 본문](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/symmetric-columns.md): 같은 폭의 두 본문 단을 순서대로 읽고 전폭 자료를 사이에 삽입하는 시스템입니다. (칼럼형 · 본문 · 인쇄용)
- [본문과 옆주석](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/text-with-notes.md): 주된 본문과 해당 문단의 용어·근거·예외를 구분하면서 가까이 연결하는 시스템입니다. (칼럼형 · 본문 · 인쇄용)
- [설명과 도판](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/slide-text-visual.md): 왼쪽 다섯 열에 설명을, 오른쪽 일곱 열에 도식이나 제품 화면을 두는 발표 화면입니다. (칼럼형 · 본문과 이미지 · 발표용)
- [1단 본문 + 여백 주석](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-text-single-notes.md): 논증을 순서대로 읽는 보고서·백서·IM 본문에 씁니다. (칼럼형 · 본문 · 인쇄용)
- [2단 보고서 본문](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-text-two-column.md): 정보량이 많은 보고서 본문을 두 단으로 받을 때 씁니다. (칼럼형 · 본문 · 인쇄용)
- [큰 제목 + 다단 본문](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-text-title-multicolumn.md): 전략·원칙·개요처럼 이미지 없이 짜임새를 보여 줄 텍스트 쪽에 씁니다. (칼럼형 · 본문 · 인쇄용)
- [상단 이미지 + 2단 본문](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-image-top-text.md): 사례·현장 사진 두 장을 먼저 보여 주고 설명하는 쪽에 씁니다. (로우형 · 본문과 이미지 · 인쇄용)
- [본문 + 캡션 이미지 열](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-text-caption-row.md): 구축 사례·제품·현장 여러 개를 같은 크기로 비교할 때 씁니다. (모듈형 · 본문과 이미지 · 인쇄용)
- [이미지 격자 + 진술](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-image-grid-statement.md): "반복", "현장 규모"처럼 여러 장면이 하나의 주장을 받칠 때 씁니다. (모듈형 · 본문과 이미지 · 인쇄용)
- [인물 카드](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-profile-cards.md): 경영진·핵심 인력·제안 수행 인력을 소개할 때 씁니다. (모듈형 · 인물 · 인쇄용)

- [조직·지배구조 쪽](https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-org-page.md): 조직도나 지분도를 크게 두고 요점을 아래 두 단으로 설명할 때 씁니다. (계층형 · 인물 · 인쇄용)
