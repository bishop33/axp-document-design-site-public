# 요약 쪽

- 구조: 요약 · 인쇄용 · 세로
- 용도: 요약

## 적합한 내용

보고서 첫 쪽에서 판단 요지, 핵심 지표 넷, 근거 셋을 한 쪽에 모을 때 씁니다.

## 다른 구조가 필요한 때

근거가 다섯을 넘으면 요약 쪽을 두 쪽으로 나누지 말고 근거를 합칩니다.

## 적용 예시

- 적용안 준비 중

## 관찰 근거와 자체 설정

자체구성: 공개 그리드 견본의 지면 설명을 분석하거나 보고서·발표에 필요한 쪽을 같은 규칙으로 더해 12열로 다시 그린 패턴입니다. 원본 치수·필드 수·여백 값은 옮기지 않았고 실제 출력 가독성은 미검증입니다.
