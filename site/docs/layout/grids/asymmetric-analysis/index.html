근거와 해설 비대칭

넓은 근거 영역과 짧은 해석 영역을 대응시켜 수치와 판단을 함께 읽는 시스템입니다.

근거와 해설칼럼형 그리드인쇄용 · 세로현황 파악 · 투자 검토 · 대안 비교

도면과 치수

영역을 글 대신 막대로 채운 지면입니다. 굵은 막대는 제목, 가는 막대는 본문, 옅은 막대는 주석, 면은 표·차트입니다.

이 그리드의 적용 예시

기업현황근거와 해설 비대칭현황 파악 · 인쇄용 · 세로 · 3쪽

치수로 본 조판

본문 영역은 판형의 75.5%입니다(폭 177.5mm). 한 열은 26.1mm, 한 행 모듈은 72.9pt입니다. 위 여백 44pt, 아래 여백 45.9pt, 좌우 여백 46pt로 좌우가 같아 제본 쪽을 따로 두지 않았습니다.

영역열폭한 줄 글자 수 (10–9pt)본문 글줄
제목·주장6177.5mm약 72–81자—
주요 차트4117mm약 48–53자—
해석·예외256.4mm약 23–25자—
근거 표4117mm약 48–53자—
판단 조건256.4mm약 23–25자—
자료·주석6177.5mm약 72–81자—

행 모듈(행 높이 + 거터 12pt)에 본문 줄이 딱 맞는 행간은 12pt(7줄), 14pt(6줄)입니다. 13pt·13.5pt·15pt에서는 한 모듈이 6.53줄·6.29줄·5.66줄로 끊겨, 모듈 경계에 놓인 표·차트의 위아래가 본문 줄과 어긋납니다.

계산 기준: 한글 본문 한 글자 평균 0.69em(Pretendard로 보고서 문장을 잰 값, 공백·숫자 포함). ‘본문 글줄’은 본문이 흐르는 영역만 판단하며 목표 32–54자는 라틴 권장 글줄을 한글 폭으로 옮긴 자체 환산값입니다(근거).

구성 원리

  • 열 0~3을 근거 자료, 4~5를 해설로 병합하며 좌우를 독립된 본문 흐름으로 만들지 않습니다.
  • 위아래 근거 묶음마다 해설의 시작 높이를 맞추고 해당 자료의 기간·출처를 유지합니다.
  • 본문과 옆주석 시스템과 달리 넓은 영역의 주역은 도표이며 좁은 영역에는 판단 문장을 둡니다.

적합한 내용

차트·표가 핵심 근거이며 결론과 예외를 같은 위치에서 확인해야 할 때 사용합니다.

다른 구조가 필요한 때

오른쪽 해설이 장문이거나 차트의 축·라벨이 네 열 폭에 들어가지 않으면 전폭 자료로 전환합니다.

관찰 근거와 자체 설정

원문확인: NAVER PDF의 내용 관계 및 Kelman HTML. 자체구성: A4에서 4+2 역할 분담, 치수·regions는 대표배치 제안입니다.

  • NAVER 4Q24 Earnings Results — PDF4–7의 사업별 차트와 설명 관계를 참고합니다. 원본 숨은 열 수를 측정한 것은 아니며 A4 세로 적용은 자체 제안입니다.
  • Kelman Swiss 공개 설명 — 36-field와 여러 sample layouts 확인. 비대칭 분석 전용 제품이라는 뜻이 아닙니다.
