# 비교 매트릭스 쪽

경쟁사·대안·제품을 같은 항목으로 비교할 때 씁니다.

- 구조: 비교 · 인쇄용 · 세로
- 용도: 비교
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-comparison-matrix/

## 치수

| 항목 | 값 |
|---|---|
| 판형 | 595.28 × 841.89pt |
| 바탕 그리드 | 12열 × 12행 |
| 거터 | 10pt |
| 좌우 여백 | 42pt |
| 본문 영역 | 위 44pt, 높이 752pt |

## 대표 배치

- 비교 질문·결론: 1열부터 12열 × 1행부터 2행
- 항목 × 대상 비교표: 1열부터 12열 × 3행부터 8행
- 차이 요약: 1열부터 12열 × 11행부터 1행
- 평가 기준·출처: 1열부터 12열 × 12행부터 1행

## 치수로 본 조판

- 유형: 모듈형 그리드
- 본문 영역: 판형의 76.7%, 폭 180.4mm, 한 열 11.8mm, 한 행 모듈 53.5pt
- 여백: 위 44pt, 아래 45.9pt, 좌우 42pt
- 행 모듈에 줄이 맞는 행간: 16pt(4줄)

## 구성 원리

- 비교 질문·결론: 제목, 12열 × 2행
- 항목 × 대상 비교표: 표, 12열 × 8행
- 차이 요약: 본문, 12열 × 1행
- 평가 기준·출처: 주석, 12열 × 1행

## 적합한 내용

## 관찰 근거와 자체 설정

자체구성: 공개 그리드 견본의 지면 설명을 분석하거나 보고서·발표에 필요한 쪽을 같은 규칙으로 더해 12열로 다시 그린 패턴입니다. 원본 치수·필드 수·여백 값은 옮기지 않았고 실제 출력 가독성은 미검증입니다.
