# 단계 넷(발표)

실행 단계를 네 개로 나눠 산출물과 함께 보여줄 때 씁니다.

- 구조: 절차·일정 · 발표용 · 가로
- 용도: 절차·일정
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/kp-slide-process/

## 치수

| 항목 | 값 |
|---|---|
| 판형 | 960 × 540pt |
| 바탕 그리드 | 12열 × 6행 |
| 거터 | 12pt |
| 좌우 여백 | 42pt |
| 본문 영역 | 위 30pt, 높이 480pt |

## 대표 배치

- 목표: 1열부터 12열 × 1행부터 1행
- 1단계: 1열부터 3열 × 2행부터 2행
- 2단계: 4열부터 3열 × 2행부터 2행
- 3단계: 7열부터 3열 × 2행부터 2행
- 4단계: 10열부터 3열 × 2행부터 2행
- 산출물 1: 1열부터 3열 × 4행부터 2행
- 산출물 2: 4열부터 3열 × 4행부터 2행
- 산출물 3: 7열부터 3열 × 4행부터 2행
- 산출물 4: 10열부터 3열 × 4행부터 2행
- 기간·담당: 1열부터 12열 × 6행부터 1행

- 유형: 칼럼형 그리드

## 관찰 근거와 자체 설정

자체구성: 공개 그리드 견본의 지면 설명을 분석하거나 보고서·발표에 필요한 쪽을 같은 규칙으로 더해 12열로 다시 그린 패턴입니다. 원본 치수·필드 수·여백 값은 옮기지 않았고 실제 출력 가독성은 미검증입니다.
