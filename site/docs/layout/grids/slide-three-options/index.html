대안 셋 비교

대안 세 개를 같은 폭의 열로 나누고 같은 항목 순서로 설명한 뒤 권고를 전폭으로 두는 발표 화면입니다.

대응 비교칼럼형 그리드발표용 · 가로대안 비교 · 의사결정 발표

도면과 치수

영역을 글 대신 막대로 채운 지면입니다. 굵은 막대는 제목, 가는 막대는 본문, 옅은 막대는 주석, 면은 표·차트입니다.

이 그리드의 적용 예시

이 시스템의 실제 문서 적용안은 준비 중입니다.

치수로 본 조판

본문 영역은 판형의 81.1%입니다(폭 309mm). 한 열은 21.9mm, 한 행 모듈은 70pt입니다. 위 여백 30pt, 아래 여백 30pt, 좌우 여백 42pt로 좌우가 같아 제본 쪽을 따로 두지 않았습니다.

행 모듈(행 높이 + 거터 12pt)에 본문 줄이 딱 맞는 행간은 20.5pt(4줄), 27pt(3줄), 27.5pt(3줄), 28pt(3줄)입니다. 20pt·21pt·22pt·24pt에서는 한 모듈이 4.1줄·3.9줄·3.73줄·3.42줄로 끊겨, 모듈 경계에 놓인 표·차트의 위아래가 본문 줄과 어긋납니다.

계산 기준: 한글 본문 한 글자 평균 0.69em(Pretendard로 보고서 문장을 잰 값, 공백·숫자 포함). 발표 화면은 문단보다 짧은 문장이 많아 글줄 목표를 두지 않았습니다.

구성 원리

  • 대안 이름은 4열씩 같은 높이로 두고 항목 순서를 똑같이 맞춥니다.
  • 권고는 대안 아래 전폭 한 행에 두고 선택 조건을 함께 씁니다.
  • 세 열에 같은 문장을 반복하지 않습니다.

적합한 내용

도입 방식, 투자 구조처럼 서로 배타적인 선택지 가운데 하나를 고르게 할 때 사용합니다.

다른 구조가 필요한 때

대안이 넷 이상이거나 비교 항목이 많으면 표 중심 비교가 맞습니다.

관찰 근거와 자체 설정

자체구성: 16:9 960×540pt, 12열×6행 바탕과 모든 병합·regions는 AXP 대표배치 제안입니다. 원거리 투사 가독성과 실제 발표 적용은 미검증입니다.
