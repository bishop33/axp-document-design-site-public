# 영역에 담을 분량은 레이아웃이 정합니다

레이아웃과 그리드를 정하면 영역마다 담을 수 있는 정보의 양이 정해집니다. 넘치면 요약하고, 모자라면 내용을 늘리거나 배치로 채웁니다. 어떤 경우에도 핵심은 빠지지 않습니다.

- 상태: 검토 중
- 갱신: 2026-10-02
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/content-fit/

그림: 넘칠 때(피함: 글자를 줄여 다 넣고 넘침 / 권장: 결론·근거만 남기고 세부는 표·부록) · 모자랄 때(피함: 위에 몰리고 아래 공백 / 권장: 제목·내용 위, 참조 문구 아래로 한 묶음)

## 맞추는 순서

1. **콘텐츠 양에 맞는 레이아웃을 먼저 고릅니다.** 아래 두 방법은 그래도 남는 차이를 다룹니다.
2. **넘치면 레이아웃에 맞게 요약합니다.** 글자를 줄이거나 간격을 깎아 억지로 넣지 않습니다. 결론, 근거 수치, 조건·한계는 남기고 세부는 표·부록·출처로 보냅니다.
3. **모자라면 먼저 내용을 늘립니다.** 근거, 비교 기준, 해석처럼 늘릴 내용이 있으면 늘립니다. 의미 없는 문장으로 채우지 않습니다.
4. **더 늘릴 내용이 없으면 배치로 채웁니다.** 제목과 내용은 영역 위쪽, 작은 참조 문구(출처, 기준일, 주석)는 영역 아래쪽에 둡니다.

## 왜 배치로 채워지나

사람은 같은 영역 안의 위쪽 제목·내용과 아래쪽 참조를 하나의 묶음으로 봅니다. 그래서 가운데 공간이 빈자리가 아니라 그 묶음의 여백으로 읽힙니다. 위에만 몰아 두면 아래 공간은 묶음 밖의 공백이 되어 지면이 비어 보입니다.

> **지킬 것** 요약하든 배치로 채우든, 독자가 판단하는 데 필요한 핵심 내용이 빠졌는지 마지막에 확인합니다. 밀도를 채우는 일보다 누락이 없는 것이 먼저입니다.
