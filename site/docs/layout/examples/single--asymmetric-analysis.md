# 기업현황 · 근거와 해설 비대칭

매출은 성장하지만 회수 지연으로 현금 전환이 약해져 채권 관리 조건이 필요합니다.

- 매체: 인쇄용 · 세로 · 3쪽
- 그리드: 근거와 해설 비대칭 (https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/asymmetric-analysis/)
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/examples/single--asymmetric-analysis/

## 이 문서의 독자와 목적

- 독자: 신규 여신을 검토하는 기업금융 심사역
- 판단할 일: 운전자금 한도 10억 원의 조건부 승인 여부
- 핵심 메시지: 매출은 성장하지만 회수 지연으로 현금 전환이 약해져 채권 관리 조건이 필요합니다.

## 페이지별 질문과 근거

1. **성장 기업에 운전자금 10억 원을 추가 제공할 수 있습니까?** 2025년 매출 240억 원, 영업현금 18억 원입니다. 채권 회수 조건을 전제로 한도 증액을 검토합니다. (표·차트: 같은 연도의 영업이익과 영업현금을 선으로 비교해 현금 전환 약화를 확인합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/single--asymmetric-analysis.svg
2. **증가한 이익이 현금으로 얼마나 전환됐습니까?** 현금은 20+18−12−2=24억 원입니다. 영업현금의 3분의 2가 설비투자에 쓰였습니다. (표·차트: 기초·기말 현금을 0기준 막대로 비교하고 세 활동별 증감은 부호가 있는 표로 확인합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/single-finance--asymmetric-analysis.svg
3. **매출 성장이 반복 가능하고 고객 위험이 분산돼 있습니까?** 매출 증가 40억 원 중 장비가 24억 원입니다. 상위 고객 집중도는 55%로 유지됐습니다. (표·차트: 누적 막대로 연도별 총매출과 세 사업의 구성 변화를 함께 확인합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/single-business--asymmetric-analysis.svg

## 배치에 적용한 기준

- 넓은 네 열의 차트·표를 두 열의 해석과 대응시킵니다.
- 수치 근거를 먼저 읽고 집행 조건을 확인합니다.
- 배경 원고는 하단 두 단으로 보존합니다.

## 판형과 조판 사양

| 항목 | 값 |
|---|---|
| 판형 | 인쇄 세로 |
| 크기 | 595.28 × 841.89pt |
| 본문 | 8.5pt / 12pt |
| 표 | 8.1~8.5pt |
| 차트 | 흑백 / 8pt |
| 그리드 | 6열 × 9행 / 거터 12pt |

## 적용 조건

운전자금 한도 10억 원의 조건부 승인 여부

가상 수치를 실제 판단에 사용하지 않습니다. 판형 변경 효과와 배치 효과를 구분합니다.

회사·수치·전망은 자체 가상 원장입니다. 참고 출처의 실적을 사용하지 않았습니다. 도표 근거부터 판단. 실제 병합은 페이지별로 다릅니다.
