# 산업분석 · 대칭 2단 본문

시장 수요는 증가하지만 부품 원가와 회수 지연을 고려해 확정 수주에 맞춰 투자해야 합니다.

- 매체: 인쇄용 · 세로 · 2쪽
- 그리드: 대칭 2단 본문 (https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/symmetric-columns/)
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/examples/slide-chart/

## 이 문서의 독자와 목적

- 독자: 생산능력 확대를 검토하는 한빛비전 경영진
- 판단할 일: 2026년 설비투자 14억 원의 단계 집행 여부
- 핵심 메시지: 시장 수요는 증가하지만 부품 원가와 회수 지연을 고려해 확정 수주에 맞춰 투자해야 합니다.

## 페이지별 질문과 근거

1. **시장 확대가 한빛비전의 증설을 정당화합니까?** 가상 시장규모는 2025년 1,250억 원으로 13.6% 성장했고 2026년 기준 전망은 10.4%입니다. (표·차트: 동일 단위의 연도별 선으로 시장 성장 추세를 보여주고 전망은 표에서 분리합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/slide-chart.svg
2. **수요·원가 충격에 따라 회사 이익과 자금 부담이 얼마나 달라집니까?** 기준 매출 270억 원, 영업이익 32억 원이지만 하방 이익은 18억 원으로 낮아집니다. (표·차트: 시나리오별 영업이익 비교로 같은 단위의 하방 폭을 확인하고 전제는 표로 제시합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/slide-chart-company-impact.svg

## 배치에 적용한 기준

- 왼쪽 단을 읽은 뒤 오른쪽 단으로 논증이 이어집니다.
- 전폭 표는 두 단의 좁은 폭에서 분리합니다.
- 하단 차트와 출처가 본문의 수치 해석을 뒷받침합니다.

## 판형과 조판 사양

| 항목 | 값 |

| 판형 | 인쇄 세로 |
| 크기 | 595.28 × 841.89pt |

| 차트 | 흑백 / 8pt |
| 그리드 | 6열 × 9행 / 거터 12pt |

## 적용 조건

2026년 설비투자 14억 원의 단계 집행 여부

가상 수치를 실제 판단에 사용하지 않습니다. 판형 변경 효과와 배치 효과를 구분합니다.

회사·수치·전망은 자체 가상 원장입니다. 참고 출처의 실적을 사용하지 않았습니다. 긴 해설과 근거를 정독. 실제 병합은 페이지별로 다릅니다.
