# 사업보고서 본문 기준선

두 단 본문의 글줄 높이를 맞춘 조판 예시입니다.

- 매체: 인쇄용 · 세로 · 1쪽
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/examples/baseline/

## 이 문서의 독자와 목적

- 독자: 인쇄 보고서 편집자
- 판단할 일: 본문 조판 조건 선택
- 핵심 메시지: 두 단 본문의 글줄 높이를 맞춘 조판 예시입니다.

## 페이지별 질문과 근거

1. **실제 판형에서 본문을 읽을 수 있습니까?** 두 단 본문의 글줄 높이를 맞춘 조판 예시입니다. (표·차트: 차트 없음. 동일 원고의 조판 조건을 비교합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/baseline.svg

## 배치에 적용한 기준

- 본문은 9pt, 행간은 13.5pt로 두고 양쪽 단의 글줄 기준을 맞춥니다.
- 빨간 기준선은 글자의 눈에 보이는 아래 끝이 아니라 baseline입니다.
- 표·제목·주석까지 모두 기준선에 억지로 붙이지 않고 본문 단에 우선 적용합니다.

## 판형과 조판 사양

| 항목 | 값 |
|---|---|
| 판형 | A4 세로 |
| 본문 | 9pt / 행간 13.5pt |
| 단 | 2단 |
| 기준선 | 본문 baseline만 표시 |
| 상태 | 자체 조판 실험 |

## 적용 조건

긴 본문 단이 나란히 있는 사업보고서·분석보고서에 씁니다.

큰 제목이나 표 행을 같은 간격에 억지로 맞추면 오히려 정보 관계가 흐려집니다.

교육용 자체 원고·수치입니다.
