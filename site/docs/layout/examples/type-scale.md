# 기업보고서 본문 크기 비교

같은 원고에서 본문 크기와 밀도를 비교합니다.

- 매체: 인쇄용 · 세로 · 1쪽
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/examples/type-scale/

## 이 문서의 독자와 목적

- 독자: 인쇄 보고서 편집자
- 판단할 일: 본문 조판 조건 선택
- 핵심 메시지: 같은 원고에서 본문 크기와 밀도를 비교합니다.

## 페이지별 질문과 근거

1. **실제 판형에서 본문을 읽을 수 있습니까?** 같은 원고에서 본문 크기와 밀도를 비교합니다. (표·차트: 차트 없음. 동일 원고의 조판 조건을 비교합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/type-scale.svg

## 배치에 적용한 기준

- 글자 크기만 바꿔도 줄 수와 페이지 밀도가 달라집니다.
- 8.5pt가 항상 좋다는 뜻이 아니라 실제 인쇄와 독자 조건에서 확인할 후보입니다.
- 기업보고서 예시는 웹 카드보다 작은 본문과 촘촘한 표·주석을 견뎌야 합니다.

## 판형과 조판 사양

| 항목 | 값 |
|---|---|
| 판형 | A4 세로 |
| 본문 후보 | 8.5 / 9.5 / 10.5pt |
| 행간 | 13.5pt 고정 |
| 폭 | 120mm |
| 검증 | 100% PDF·실물 출력 필요 |

## 적용 조건

보고서 본문 크기 후보를 고르기 전 비교할 때 씁니다.

화면 확대 상태에서만 보고 작다거나 크다고 판단하지 마세요.

교육용 자체 원고·수치입니다.
