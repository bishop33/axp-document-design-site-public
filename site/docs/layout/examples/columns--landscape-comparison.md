# 투자검토 IM · 가로 항목 대조

ARR 성장과 기존 고객 확장을 확인하되 집중도와 해외 회수기간을 투자 조건에 반영합니다.

- 매체: 인쇄용 · 가로 · 3쪽
- 그리드: 가로 항목 대조 (https://bishop33.github.io/axp-document-design-site-public/docs/layout/grids/landscape-comparison/)
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/layout/examples/columns--landscape-comparison/

## 이 문서의 독자와 목적

- 독자: 성장투자 펀드의 투자심의위원
- 판단할 일: 투자 전 지분가치 600억 원 기준 120억 원 투자의 실사 착수
- 핵심 메시지: ARR 성장과 기존 고객 확장을 확인하되 집중도와 해외 회수기간을 투자 조건에 반영합니다.

## 페이지별 질문과 근거

1. **120억 원 투자를 위한 실사에 착수할 근거가 충분합니까?** 2025년 ARR은 160억 원에서 214억 원으로 증가했고 기존 고객 NRR은 118.8%입니다. (표·차트: 기초·기말 ARR은 0기준 막대로, 신규·확장·축소·이탈은 증감 숫자표로 구분합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/columns--landscape-comparison.svg
2. **고객 확장이 일부 대형 계정에만 의존합니까?** 2025년 초 고객 80개사 중 76개사가 잔존했고 기존 고객 ARR은 30억 원 증가했습니다. (표·차트: 기초·기말 ARR 비교 막대로 코호트별 확장 규모를 동일 단위로 대조합니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/columns-market--landscape-comparison.svg
3. **성장이 지연될 때 현금과 투자 조건이 버틸 수 있습니까?** 기존 현금 54억 원은 월 순유출 3억 원 기준 18개월입니다. 신규 투자금은 아직 포함하지 않았습니다. (표·차트: 동일 기준의 시나리오 비교로 현금 소진 속도가 runway에 주는 영향을 보여줍니다.) — 지면: https://bishop33.github.io/axp-document-design-site-public/guide/examples/columns-risk--landscape-comparison.svg

## 배치에 적용한 기준

- 대표 내지에서 공통 속성별 대상 값을 대응시킵니다.
- 기간은 왼쪽, 금액은 오른쪽에 정렬하고 사용처 합계와 지분가치 그룹을 구분합니다.
- 카탈로그 기본6행을16행으로 세분한 자체 pilot으로 상단 예약과 하단 본문 간격을 재배분합니다.

## 판형과 조판 사양

| 항목 | 값 |
|---|---|
| 판형 | 인쇄 가로 |
| 크기 | 841.89 × 595.28pt |
| 본문 | 8.5pt / 12pt |
| 표 | 8.1~8.5pt |
| 차트 | 흑백 / 8pt |
| 그리드 | 8열 × 16행 / 거터12pt, 자체 IM pilot |
| 본문 간격 | 8.5pt / 12pt, 문단 후 추가9pt |
| 중앙 경계 | 바탕 거터12pt + 양쪽 안쪽 여백8pt씩 |
| 표 셀 안쪽 여백 | 좌우8pt, 첫 열 왼쪽0pt; 행 추가량과 별도 |

## 적용 조건

투자 전 지분가치 600억 원 기준 120억 원 투자의 실사 착수

가상 수치를 실제 판단에 사용하지 않습니다. 판형 변경 효과와 배치 효과를 구분합니다.

회사·수치·전망은 자체 가상 원장입니다. 참고 출처의 실적을 사용하지 않았습니다. 직접 IM 원문은 미확보이며 거래·실사 구성은 자체 제안입니다. 가로 지면에서 항목 대조. 실제 병합은 페이지별로 다릅니다. 보유 비Kelman PDF의 새 지면 관찰을 참고한 자체 간격 pilot입니다. 신규 외부 원문 확보는 도구장애로 미완료이며 관찰값을 권장값으로 복제하지 않았습니다.
