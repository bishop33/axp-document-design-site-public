적용 조건과 참고 자료

2026 해외 예산 24억 원의 단계 집행 동의

가상 수치를 실제 판단에 사용하지 않습니다. 판형 변경 효과와 배치 효과를 구분합니다.

회사·수치·전망은 자체 가상 원장입니다. 참고 출처의 실적을 사용하지 않았습니다. 발표용 원고를 두 적용안에 동일하게 사용했습니다. 원거리 투사는 미검증입니다. 큰 차트로 변화 설명. 실제 병합은 페이지별로 다릅니다.

  • 원문확인: Kelman HTML과 NAVER PDF 선택 지면. 자체구성: 960×540pt, 병합·regions는 대표배치 제안이며 원거리 투사는 미검증입니다.
  • 그리드 참고: Kelman Highlight Presentation 공개 설명 — 간결한 발표용 콘텐츠를 longer-form Insight와 구분합니다. 48/36-field 명시는 우리 치수의 근거가 아닙니다.
  • 그리드 참고: NAVER 4Q24 Earnings Results — 사업별 차트·해설 관계 참고. 기존 발표 자료의 글자 크기를 원거리 가독성 기준으로 채택하지 않습니다.
  • 내용 구성 참고: NAVER 4Q24 Earnings Results, PDF 2–7 — 리서처가 확보 PDF 본문 및 PDF3 시각을 확인했습니다. 지표 정의·기간·잠정 성격을 밝히는 구성만 참고했습니다. 오르빗의 ARR·코호트·연간 실적은 가상값이며 NAVER 실적과 혼합하지 않았습니다.
