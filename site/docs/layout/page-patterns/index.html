지면은 역할별 패턴으로 미리 정해 둡니다

표지, 목차, 섹션, 본문, 강조, 수치, 마감처럼 지면의 역할마다 반복해서 쓰는 배치가 있습니다. 공개 그리드 견본의 지면 설명 856건에서 찾은 패턴을 12열 스켈레톤으로 다시 그린 30종입니다.

검토 중2026.09.29 갱신

20개 패턴

  • 검은 타이포 표지

    표지

    기업현황 보고서·IM 표지처럼 요소가 적고 첫인상을 강하게 만들 때 씁니다.

  • 분할 표지

    표지

    표지에서 문서 구성을 함께 보여 줄 때 씁니다.

  • 번호 목록형 목차

    목차

    장이 5–10개인 보고서의 목차입니다.

  • 검은 면 + 목차

    목차

    견본 펼침면의 "왼쪽 검은 쪽 + 오른쪽 목차"를 단면 A4 한 쪽으로 줄인 형태입니다.

  • 번호 섹션면

    섹션

    이미지 없이 여백과 큰 번호로 장을 나눌 때 씁니다.

  • 핵심 진술 + 목차면

    섹션

    장 도입에서 요지와 문서 안 위치를 함께 보여 줄 때 씁니다.

  • 이미지 섹션면

    섹션

    현장 사진·제품 사진이 있는 브로슈어나 기술제안서의 장 구분에 씁니다.

  • 1단 본문 + 여백 주석

    본문

    논증을 순서대로 읽는 보고서·백서·IM 본문에 씁니다.

  • 2단 보고서 본문

    본문

    정보량이 많은 보고서 본문을 두 단으로 받을 때 씁니다.

  • 큰 제목 + 다단 본문

    본문

    전략·원칙·개요처럼 이미지 없이 짜임새를 보여 줄 텍스트 쪽에 씁니다.

  • 상단 이미지 + 2단 본문

    본문과 이미지

    사례·현장 사진 두 장을 먼저 보여 주고 설명하는 쪽에 씁니다.

  • 본문 + 캡션 이미지 열

    본문과 이미지

    구축 사례·제품·현장 여러 개를 같은 크기로 비교할 때 씁니다.

  • 이미지 격자 + 진술

    본문과 이미지

    "반복", "현장 규모"처럼 여러 장면이 하나의 주장을 받칠 때 씁니다.

  • 검은 면 전면 인용

    강조

    문서의 요지 한 문장을 기억시킬 때 한두 번만 씁니다.

  • 본문 속 큰 인용

    강조

    긴 본문 중간에 강약을 줄 때 씁니다.

  • 수치 블록 + 해설

    수치

    기업현황 보고서·IM 요약 쪽에서 핵심 지표 3–4개를 보여 줄 때 씁니다.

  • 차트 + 해설

    수치

    시계열·구성비를 한 차트와 해설로 보여 줄 때 씁니다.

  • 수치·재무표 쪽

    수치

    재무·사양·지표 표를 본문 폭 전체로 싣는 쪽입니다.

  • 인물 카드

    인물

    경영진·핵심 인력·제안 수행 인력을 소개할 때 씁니다.

  • 마감면

    마감

    표지 요소를 줄여 반복하는 뒤표지입니다.

내용먼저 쓸 패턴대안쓰지 않을 패턴
서술(논증·설명)1단 본문 + 여백 주석, 2단 보고서 본문큰 제목 + 다단 본문검은 지면의 긴 본문
수치 요약큰 숫자 KPI(지표 1개), 수치 블록 + 해설(3–4개)핵심 진술 + 목차면이미지 모자이크
시계열·구성비차트 + 해설수치·재무표 쪽항목 많은 도넛
비교대칭 표 비교수치·재무표 쪽인용 + 이미지
절차·사례본문 + 캡션 이미지 열, 상단 이미지 + 2단 본문이미지 격자 + 진술분석 없는 카드 나열
조직·사람인물 카드큰 제목 + 다단 본문명암 분할
인용·증언본문 속 큰 인용, 인용 + 이미지검은 면 전면 인용(문서당 1–2회)수치 블록
목차·탐색번호 목록형 목차, 검은 면 + 목차핵심 진술 + 목차면이미지 섹션면 안의 목차

조합할 때 지킬 것

  • 강조 쪽(검은 면 인용, 큰 숫자, 짧은 진술, 이미지 섹션면)을 연달아 두지 않습니다. 사이에 본문이나 표 쪽을 둡니다.
  • 섹션면은 한 문서에서 한 종류만 씁니다. 띠 높이와 번호 위치를 고정해야 탐색 표지가 됩니다.
  • 수치는 큰 숫자 → 수치 블록 → 차트 → 표 순서로 자세해집니다. 요약 쪽에 큰 표를, 부록에 큰 숫자를 두지 않습니다.
  • 이미지가 적은 보고서는 이미지 대신 여백·번호·검은 면으로 강약을 만듭니다.
  • 검은 지면은 표지·섹션면·마감면에만 쓰고, 본문과 표는 흰 지면에 둡니다.

문서 유형별 흐름은 기업현황 보고서, 투자검토 IM, 기술제안서, 산업분석, 발표 자료에 있습니다.

출처와 범위Stephen Kelman의 공개 그리드 상품 68종 견본 설명(이미지 대체 텍스트)을 읽고 역할과 배치를 분류했습니다. 이미지 자체는 보지 못했고 원본 치수·필드 수·여백 값은 옮기지 않았습니다. 빨간 강조의 스위스 양식은 원작자의 고유한 표현이라 가져오지 않았습니다.
