# 역할마다 책임지는 판단이 다릅니다

기획·리서치·검증·편집·디자인·검수의 여섯 역할이 각자 한 가지 판단을 책임집니다. 역할은 사람 수가 아니라 판단의 종류이며, 에이전트로 나눌 때도 같은 경계를 씁니다.

- 상태: 검토 중
- 갱신: 2026-09-29
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/workflow/roles/

| 역할 | 책임지는 판단 | 산출물 | 넘기기 전 확인 |
|---|---|---|---|
| 기획 | 누구에게 무엇을 결정하게 할까 | 문서 개요, 질문 목록, 전달 형식 | 독자와 결정할 일이 한 문장으로 적혀 있다 |
| 리서치 | 무엇을 근거로 쓸 수 있을까 | 자료 목록(출처·기준일·범위), 원문 발췌 | 2차 자료만으로 핵심 수치를 쓰지 않았다 |
| 검증 | 이 수치와 주장은 맞는가 | 데이터 원장, 확인·미확인 표시, 반론 | 산식을 다시 계산했고 합계가 맞다 |
| 편집 | 어떤 순서로 읽혀야 이해될까 | 원고, 쪽 구성, 쪽별 결론 문장 | 결론 문장만으로 요약이 된다 |
| 디자인 | 어떻게 보여야 빨리, 틀리지 않게 읽힐까 | 지면, 표·차트·도식, 그리드 설정 | 강조가 쪽마다 한 곳이고, 같은 역할은 같은 자리에 있다 |
| 검수 | 독자가 받는 형식에서 문제가 없는가 | 검수 기록(P0–P2), 재검수 결과 | 화면·PDF·실물을 따로 확인했다 |

## 역할을 나눌 때 지킬 것

- 집필(편집)과 내용 검수(검증)는 다른 역할이 맡습니다.
- 디자인은 내용을 바꾸지 않습니다. 줄이거나 차트를 바꿔 의미가 달라지면 편집에 되돌립니다.
- 역할 이름은 전문성을 보장하지 않습니다. 외부 전문가 확인이 필요한 항목은 따로 표시합니다.
- 에이전트에게 역할을 줄 때는 이 표의 한 행과 [작업 흐름](/docs/workflow/process/)의 해당 단계를 함께 줍니다.
