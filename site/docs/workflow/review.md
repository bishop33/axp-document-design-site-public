# 검수는 다섯 단계를 따로 통과해야 합니다

내용이 맞아도 화면에서 깨지고, 화면이 맞아도 PDF와 종이에서 달라집니다. 내용·화면 렌더·PDF·실물 출력·디자인 QC를 각각 확인하고 기록합니다.

- 상태: 검토 중
- 갱신: 2026-09-29
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/workflow/review/

검수 단계 (Mermaid 원고)

```mermaid
flowchart LR
  c["`**내용 검수**
```

## 단계별로 보는 것

| 단계 | 확인 방법 | 주로 찾는 문제 |
|---|---|---|
| 내용 검수 | 원장과 원고 대조, 산식 재계산 | 같은 수치가 쪽마다 다름, 결론과 근거 불일치, 기준일 누락 |
| 화면 렌더 | Chrome에서 A4·100%로 열기 | 넘침, 줄바꿈, 글꼴 대체, 빈 쪽 |
| PDF | 인쇄용 PDF로 저장 후 확대 | 면색 누락, 선 굵기 변화, 쪽 나눔 |
| 실물 출력 | 용지 맞춤 끄고 100% 인쇄 | 작은 글자·주석 가독성, 여백, 제본 쪽 |
| 디자인 QC | 쪽을 펼쳐 놓고 비교 | 위계 혼란, 강조 과다, 정렬선 불일치, 밀도 차이 |

## 지적의 무게

| 등급 | 뜻 | 처리 |
|---|---|---|
| P0 | 독자가 틀린 판단을 하게 만듦(잘못된 수치, 반대 결론) | 전달 중지, 즉시 수정 |
| P1 | 읽기를 방해하거나 신뢰를 떨어뜨림(불일치, 깨짐) | 전달 전 수정 |
| P2 | 더 나아질 수 있음(간격, 표현 선택) | 기록 후 다음 판에서 |

## 지킬 것

- 단계마다 무엇을 확인했고 무엇을 확인하지 못했는지 적습니다. 확인하지 않은 단계를 통과로 쓰지 않습니다.
- 지적은 쪽 번호와 위치, 기대한 모습, 실제 모습으로 적습니다.
- 수정한 뒤에는 수정한 단계부터 다시 통과합니다.
- 반복된 지적은 [개선](/docs/workflow/process/) 단계에서 이 가이드의 규칙으로 옮깁니다.
