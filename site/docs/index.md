# 문서 디자인 가이드

기업 보고서와 발표 자료를 만들 때 쓰는 기본 원칙, 그리드, 차트, 실제 문서 레퍼런스와 제작 시험을 한곳에 모았습니다.

- 상태: 작성 중
- 갱신: 2026-09-28
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/

## 차례

1. **시작하기** — 읽는 상황, 정보 위계, 서체와 조판, 그리드, 간격, 표·차트, 연속 페이지의 기본 원칙.
2. **레이아웃** — 그리드 시스템 10종과 보고서 지면별 적용 예시.
3. **차트** — 표·차트 12종의 선택 기준, 표현 규칙, 예시.
4. **견본과 예시** — 같은 내용을 표, 문장, 차트, 구조로 보여 준 견본.
5. **레퍼런스** — 실제 PDF·문서에서 추출한 내지 미리보기와 분석.
6. **문서 제작** — 문서 유형별 제작과 검수 기록.
7. **팀과 기록** — 역할, 학습 기록, 서체 라이선스.
