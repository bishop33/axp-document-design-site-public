# 문서 디자인 가이드

정보를 사람이 빨리, 틀리지 않게 읽도록 배치하고 표현하는 방법입니다. 사람과 에이전트가 같은 원칙으로 기업 보고서와 발표 자료를 만들 수 있게 원칙, 레이아웃, 표현, 작업 흐름, 문서 유형 순서로 정리했습니다.

- 상태: 작성 중
- 갱신: 2026-09-29
- 주소: https://bishop33.github.io/axp-document-design-site-public/docs/

## 차례

1. **소개** — 이 가이드가 다루는 것과 읽는 순서.
2. **원칙** — 읽는 상황, 순서와 위계, 서체, 간격, 표현 선택, 연속 페이지. 모든 정보 전달 콘텐츠에 공통입니다.
3. **레이아웃** — 그리드의 정의와 유형, 설계 원리, 그리드 시스템 17종과 페이지 패턴 54종, 가상 원고를 채운 적용 예시.
4. **차트·도식** — 표·차트 33종과 도식 16종. 독자의 질문에 맞춰 고르고, 공통 라이브러리로 그립니다.
5. **제작 흐름** — 목적 → 수집 → 검증 → 구조화 → 표현 → 검수 → 전달 → 개선. 역할, 산출물, 통과 기준.
6. **문서 유형** — 유형별 쪽 구성, 쪽마다 답할 질문과 표현.
7. **레퍼런스** — 실제 PDF·문서에서 추출한 지면과 분석, 원본 관찰 기록.
8. **부록** — 서체·라이선스, 내부 역할과 학습 기록.
