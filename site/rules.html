문서 편집의 공통 기준

수치는 조정 가능한 시작값입니다. 화면 확대보다 실제 인쇄 크기에서 읽힘을 확인합니다.

01 / 페이지와 정렬

A4 세로 210 × 297mm를 기본으로 합니다. 좌우 여백은 17–18.5mm 중 문서별 하나를 선택합니다. 본문·표·차트 외곽의 좌우 기준선을 통일합니다.

텍스트 열은 왼쪽, 숫자 열은 오른쪽 정렬합니다. 열 제목도 해당 내용과 동일하게 정렬합니다. 단위·기간·소수 자릿수를 통일합니다.

03 / 여백과 그룹핑

  • 페이지 여백, 섹션 사이, 제목과 내용 사이, 박스 내부 간격을 구분합니다.
  • 독립 섹션 사이 18–28pt, 제목과 내용 사이 6–12pt를 시작점으로 사용합니다.
  • 차트는 제목·단위·범례·출처까지 한 박스로 묶습니다.
  • 박스 테두리와 같은 역할의 외부 구분선은 중복해서 넣지 않습니다.
  • 외곽 박스는 본문 폭에 맞추되 내부 그래픽과 글자를 함께 확대하지 않습니다.

04 / 표현 방식 선택

  • 속성 설명은 왼쪽 헤더 표, 반복 비교는 상단 헤더 표로 표현합니다.
  • 다중 헤더는 회색 면의 농도로 계층을 구분합니다. 본문 면은 흰색을 유지합니다.
  • 차트는 규모·추이·구성비 등 실제 비교 관계가 있을 때 사용합니다.
  • 도식은 소속·거래·순서·대안·조건을 구분합니다. 같은 형태는 같은 의미로 사용합니다.
  • 한 장 요약은 전폭과 좌우 2단을 조합하고, 내용이 많으면 상세 페이지로 연결합니다.

05 / 초기 기업 파악 자료

기업보고서 사례의 추가 확인사항은 ‘확인할 내용 → 자료 근거와 대출 관점의 이유 → 필요한 자료’로 간결하게 적습니다. 회신 전·후 관리 화면이나 클릭 가능한 체크박스를 사용하지 않습니다.

자료 미확보를 부실로 단정하지 않으며, 가상·미확인·0을 구분합니다. 대출 관점의 내용 규칙은 기업보고서 사례에 한정되며 회사소개서 등 모든 문서의 공통 요건은 아닙니다.

06 / 출력과 검수

Word와 PPT는 공통 디자인 언어를 사용하되 페이지 크기와 글자 크기를 별도로 설계합니다. 차트·도식은 SVG 또는 PNG로 삽입할 수 있습니다. 삽입된 실제 크기에서 라벨·선·범례를 확인합니다.

A4 100% 인쇄에서 글자 뭉침, 잘림, 줄바꿈, 표 정렬과 출처 가독성을 검수합니다. 한 페이지에 맞추기 위해 모든 글자를 무조건 축소하지 않습니다.
