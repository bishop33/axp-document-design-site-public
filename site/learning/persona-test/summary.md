# 보고서 제작 시뮬레이션 1차 결과

## 결론
현재 자료로 **지원된 원고를 실제 보고서 초안으로 구성하는 작업은 가능**했다. 그러나 스타일·출력·예외 처리의 여러 결정을 제작자가 보충했다. 실제 렌더·출력·독자 시험 없이 '가이드만으로 일관된 고품질 보고서를 만들 수 있다'고 결론 내릴 수 없다. 상태는 검토용 초안, Bishop 검토 대기다.

## 시험 설계
- 동일 모델의 독립 에이전트가 경영기획 담당자(analyst), 편집 디자이너(designer), 명시적 규칙 중심 생성기(llm)를 모사했다. 실제 사람/모델간 성능 비교가 아니다.
- 같은 가상 원장과 과제: 2025 경영성과를 이사회에 설명하고 2026년 8명·연간6억원 채용 요청을 판단하는 A4세로4쪽. 표지 전용 지면은 없었다.
- 기본 가이드·그리드·차트·예시·레퍼런스·학습 기록의 관련 항목을 읽었다. 모든 문서·예시를 전수 정독하거나 실제 웹 메뉴를 사용한 시험은 아니다. topics.js 외부에 있는 context 본문은 공통 미확인 범위로 남았다.
- 공개 JS/JSON을 직접 읽고 AI가 HTML을 구현하므로 일반 비디자이너보다 유리한 조건이다. persona별 실제 숙련도·시간·이해 속도 차이는 측정하지 않았다.
- input-snapshot.json은 제작 전 6개 공개 입력의 hash다. 테스트 후 추가한 NBIM13·17쪽과 학습 노트는 이번 제작의 입력 성과로 소급하지 않는다.

## 실제 수행자
- Zeno: analyst 4쪽, 원장/선택/가정 기록.
- Parfit: designer 4쪽, 폭 병합/조판 판단 기록.
- Kierkegaard: llm 4쪽, 규칙과 예외 직렬화.
- Herschel: 보유 NBIM 원본에서13·17쪽 추출·관찰. 신규문서0종.
- Singer: 제작자와 별도 소스 수준 내용·출처 QC. 실제 시각/출력 QC는 아님.
- 총괄: 공통 과제·입력 고정, 구조 검사, 결과 통합, QC 회신 중계, 사이트 학습 기록과 연결. 총괄 검사를 독립 QC로 계산하지 않는다.

## 검증과 발견
- 구조 검사: 3개 report.html 각각 data-page1~4, 가상 표시, 외부 자산 의존 없음, decisions/findings 존재. structural-validation.json에 최종 report hash를 보존한다. 검사 범위는 소스 구조이며 모든 HTML/CSS 적합성·금융 의미를 자동 인증하지 않는다.
- 독립 QC 최초 C1~C5(논증·원장·산식·한계)는 세 조건 모두 소스 범위 통과. C6는 analyst/designer 통과, llm의 p4 정성표 용도 변경 설명 누락으로 부분 충족. 자세한 판정과 후속 재검수는 independent-qc.md가 기준이다.
- 재검수: 제작자가 정성표 adaptation을 명시했고 총괄은 QA 지시 주체의 잘못된 사용자 귀속을 바로잡았다. 독립 검수자가 Q3/Q7 및 늦게 도착한 기록 Q4를 closed로 확인했다. 최종 C1~C6는 세 조건 모두 소스 범위 통과이며, 보고서 본문·조판은 바꾸지 않았다. C7/C8 및 전체 UI/context 동선은 미검증 그대로다.
- 실제 결함: llm의 provenance 누락 및 초안 기록의 언어 혼입. 기록 수정은 조판 품질 개선과 구분한다. analyst 기록 늦은 도착은 초기 검사 시점의 증거 공백이지 작성 능력 실패가 아니다.
- 검증 공백: 실제 보고서 렌더·PDF4쪽·서체·겹침·잘림·여백·읽는 흐름·실물/독자 시험. 기존 브라우저 검사 스크립트 실행은 Chromium 시작 권한 오류로 실패했고 재시도/우회하지 않았다. 소스의 4개 영역을 최종 출력4쪽으로 보고하지 않는다.
- 실패 조건을 가린 채 개선하지 않았다. 콘텐츠/시각 문제를 발견하려는 시험물이므로 승인 예시 목록과 분리했다.

## 레퍼런스
NBIM 한 문서의 미리보기를2쪽에서4쪽(13/15/16/17)으로 늘렸다. 전체 실제문서21종·내지43쪽, 전체기록152건(탐색후보131건). 새 외부 문서는0종이며 사용자 요청인 자료 수량 확대는 미완료다. 기존5개 기관 후보도 원본/미리보기 미확보 상태 그대로다. 템플릿 이미지도 수집 대상이지만 외부 접근 승인서비스 오류를 우회하지 않는다.
