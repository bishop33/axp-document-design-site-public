4쪽 초안

제작 기록

초안은 A4 고정 판형의 조판 시험물입니다. 실제 출력 쪽수·잘림·겹침·인쇄 가독성은 미검증이며 승인된 예시가 아닙니다.

무엇을 확인했는가

  • 제작 수행: 같은 원장으로 4개 지면씩 작성하고 페이지 질문, 선택한 그리드·차트·레퍼런스, 보충한 규칙을 남겼습니다.
  • 자료 활용: 숫자 우측 정렬, 당기 열 강조, 정확한 값은 표로 조회하기 등 기존 원칙을 실제 원고에 적용했습니다.
  • 판정의 한계: 좋은 원고와 미확인 조건은 공통 과제에서 상당 부분 제공됐습니다. 이를 가이드만의 성과로 볼 수 없습니다.
  • 별도 검증 필요: 브라우저 렌더·최종 PDF·실물 인쇄·실제 독자 시험은 통과 판정하지 않았습니다. 독립 QC도 소스와 수치 대조 범위입니다.

독립 QC 기록구조 검사공통 과제·원장종합 기록

보완 우선순위

  1. 제작 전 원고 계약: 독자·결정·필수 근거·원장·미확인값을 고정합니다. 구독 매출을 ARR로 바꾸거나 단순 잔여 현금을 전망으로 단정하지 않는 경계를 포함합니다.
  2. A4 출력 프로파일: 한글 서체·본문/표/주석 크기·행간·읽기 폭·간격·수치 표기와 적용 상태를 하나의 제작 사양으로 묶습니다. 이번 임의값을 검증 없이 정답으로 채택하지 않습니다.
  3. 예외 처리: 긴 제목·본문·표가 넘치면 분할, 폭 변경, 다음 쪽 이동을 어떤 순서로 판단할지 정합니다. 글자 축소·내용 삭제로 자동 해결하지 않습니다.
  4. 레퍼런스에서 적용까지: 원본 내지 → 관찰한 관계 → 한국어 적용 → 적용하지 않은 요소 → 검수 결과를 연결합니다.
  5. 동일 입력 재테스트: 세 초안의 렌더를 먼저 검수한 뒤, 긴 원고·누락값·다수 항목으로 조건을 바꿔 규칙이 유지되는지 확인합니다.
