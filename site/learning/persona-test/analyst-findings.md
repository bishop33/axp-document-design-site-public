# Analyst 제작 실험 기록

2026-09-22. 가상 기업의 이사회용 2025 경영성과 보고서 4쪽을 실제 HTML 원고로 작성했다. 이는 Excel 수치 해석이 가능한 비디자이너 경영기획 담당자의 AI 모사이며 실제 사람 실험이 아니다. 이 담당은 경영성과·현금흐름 원고 집필과 조판 초안 작성을 수행했다. 별도 도메인 검수자 역할은 수행하지 않았다.

## 산출물과 상태

- `report.html`: 한국어 완성 원고가 들어 있는 A4 세로 페이지 컨테이너 4개. `data-page="1"`~`"4"`를 각 article에 선언했다. 표지만으로 소비한 쪽은 없다.

- `findings.md`: 사용 근거, 결정 과정, 발견과 재테스트 조건, 소규모 QA 이력을 기록했다.

상태는 **source-only 검사까지 수행한 조판 초안, Bishop 검토 대기**다. 실제 렌더에서 넘침이 없거나 PDF가 정확히 4쪽이라고 확인한 것은 아니다. 독립 QC는 총괄 전달상 진행 중이며 이 담당은 결과를 받지 않았다. 총괄의 본문 동결 요청 이후 보고서 내용의 추가 개선은 하지 않았다.

## 실제 결정 과정

1. **판단 질문 설정**: 다음 연도 8명 채용을 바로 승인할 수 있는지로 한정했다. 회사 소개·시장 전망·경쟁력 설명은 원장이 없으므로 추가하지 않았다.
2. **원장과 해석 분리**: 3개년 실적, 구성, 분기, 현금 연결, 고객 집중, 채용 요청을 `decisions.json`의 단일 원장에 보존했다. 계산된 비율과 잔여값은 별도로 기록했다. 영업현금 감소 원인은 미확인으로 남겼다.
3. **논증의 순서 선택**: 1쪽 성과와 보류 의견, 2쪽 매출의 지속성, 3쪽 지출 부담, 4쪽 재심의 자료로 구성했다. 보류는 경영기획 관점의 판단이며 공개 디자인 가이드의 자동 결론이 아니다.
4. **그리드 선택과 보충**: 1쪽은 `financial-table`, 2~4쪽은 `continuous-text`의 배치 원칙을 채택했다. CSS 6열을 모두 병합해 공통 정렬선을 만들고 행은 내용 흐름으로 두었다. 카탈로그의 9행·region 높이를 그대로 구현하지 않았으며 이를 가이드의 정확한 재현으로 보지 않는다.
5. **표현 선택**: 3연도 다지표 조회는 `table-values`, 사업별 금액 비교는 `bar`, 승인/보류의 동등 항목 비교는 `table-matrix`를 적용했다. 매출 구성을 파이와 중복 표시하지 않고 모든 막대에 금액·비중을 함께 썼다. 현금은 부호 있는 연결표만 사용했다.
6. **실제 제작**: 외부 CSS·JS·이미지·웹폰트 호출이 없는 단일 HTML을 수동 작성했다. 기존 완성품 제작 스크립트를 실행하지 않았다. HTML/CSS 구현 능력은 AI 기술 지원이며 analyst 일반 사용자가 단독으로 만들 수 있다는 증거가 아니다.
7. **제한된 검사**: Node로 원장·산식, 페이지 컨테이너, ID, CSS 막대 비례, 외부 의존과 잘못된 마침표를 검사했다. 브라우저·네트워크·git은 시도하지 않았다. TodoWrite 도구는 제공 도구 목록에 없어서 실행하지 못했으며 이 목록이 실제 단계 기록을 대신한다.

## 구체적 발견

이 우선순위는 제작을 가로막는 영향의 구분이다. 가이드 품질의 수치 점수나 일반 사용자 성공률이 아니다.

### P1 / 원장 공백을 채우는 재무 판단은 가이드가 대신하지 못한다

**재현 근거:** `protocol.md`는 고객별 금액·갱신율·채용 시점·추가매출을 미제공한다. `examples.json`의 `single`에는 다른 가상 기업의 회수 지연 설명이 있지만 이를 현재 회사의 원인으로 옮길 수 없다. 현재 원장에는 영업이익 증가·영업현금 감소만 있다.

**제작자 영향:** 디자인 예시의 완성된 인과 설명을 복사하면 사실과 해석이 섞인다. 보류·조건부·승인 선택에는 경영기획 판단과 추가 정보가 필요하다. 이번에는 미확인 표시와 보류 의견으로 작성했다.

**보완안:** 유형별 원고 준비표에 필수 원장·계산값·미확인 원인·의사결정 조건을 분리하고, 결측이 있을 때의 표현 예시를 제공한다.

**재테스트 통과조건:** 같은 원장으로 다른 집필자가 고객 갱신·현금 감소 원인·ROI를 만들지 않고, 9−6=3을 전망으로 표기하지 않으며, 판단과 추가 자료를 연결한다. 별도 내용 QC가 이를 확인해야 한다.

### P1 / 원칙에서 출력 가능한 조판으로 옮기는 작업이 남는다

**재현 근거:** `topics.js`의 `type`·`pages`는 실제 판형 검증을 요구한다. `grid-systems.json`에 치수는 있으나 자체 제안임을 명시한다. `single` 예시는8.5/12pt다. 이번에는4쪽 원고에9.5/14.5pt와 별도 간격·footer 규칙을 보충했다.

**제작자 영향:** 공개 설명으로 표/본문 유형은 고를 수 있었으나 임의 한국어 원고가 4쪽에 들어가는지, 대체 폰트에서 넘치지 않는지까지 확정할 수 없었다. HTML 구현 지원이 필요했다. 현재 브라우저·출력 차단은 실행환경 문제이며 가이드 자체의 결함으로 귀속하지 않는다.

**보완안:** 실제 편집 가능한 정독용 기본 틀에 폰트 제공·대체 정책, 넘침 발견 절차, 제목·표 분할 점검을 연결한다. 한 숫자를 보편 권장값으로 확정하지 않는다.

**재테스트 통과조건:** 도구 제한 해제 후 원본 HTML과 통합 경로에서 렌더를 확인하고, 폰트 조건을 기록한 A4 PDF가 정확히4쪽이며 글자 잘림·표 분할·footer 겹침이 없음을 검토한다. 그 다음 독자가 수치와 한계를 읽을 수 있는지 별도로 확인한다.

### P2 / 그리드 정의를 가져와도 예외 결정을 설명해야 한다

**재현 근거:** `financial-table`은 좌우38pt·9행, `continuous-text`는 좌우62pt·9행이다. 이번 보고서는 양쪽 모두62pt와 자연 흐름을 사용했다. `learning/content.json`의 `editorial-rhythm`은 고정 높이와 글줄 맞춤이 읽기 품질을 보증하지 않는다고 설명한다.

**제작자 영향:** 초급 제작자는 페이지마다 치수를 바꿀지, 공통 정렬선을 유지할지 판단해야 한다. 이번 절충은 재사용 ID만 기록하면 원본과 동일한 규칙처럼 오해할 수 있다.

**보완안:** 선택한 시스템과 실제 적용값의 차이를 기록하는 override 양식을 공개 설명과 연결한다.

**재테스트 통과조건:** 제작자가 바탕 열과 데이터 열을 혼동하지 않고, 변경한 여백·행 모델·병합을 설명하며 실제 CSS와 기록이 일치한다.

### P2 / 레퍼런스 관찰과 한국어 적용 검증을 구분해야 한다

**재현 근거:** NBIM PDF15쪽 PNG에서 당기 열 강조와 하단 주석을 보았다. catalog도 작은 글자의 발표·축소 가독성을 주의시킨다. 영어 원본을 본 사실은 현재 한국어 주석8.5pt의 가독성 검증이 아니다.

**제작자 영향:** 어떤 시각 관계를 빌릴지는 판단할 수 있지만 원본의 폰트·여백값을 바로 이식하기 어렵다. 이번에는 관계만 적용하고 구체 크기는 가정으로 남겼다.

**보완안:** 레퍼런스별로 관찰 사실·적용한 관계·복사하지 않은 값·검증 필요 항목을 함께 기록한다.

**재테스트 통과조건:** 한국어 실제 판형에서 당기 열과 주석이 식별되는지 확인하되 원본에서 관찰하지 않은 치수를 주장하지 않는다.

## Source-only 검사 결과

Node의 실제 종료코드0으로 다음 범위가 통과했다. 브라우저 DOM 검사나 HTML 표준 validator 전체 검사는 아니다.

- article4개와 `data-page` 1/2/3/4, 각 쪽 제목과 footer, A4 portrait 및210×297mm 선언 확인.
- 실제 HTML `id`10개 중복 없음. 선택한 grid/chart IDs와 HTML data 속성 연결 확인.
- 외부파일 참조, script/link/iframe/img 요소, CSS url/@import 없음. 상대경로도 없어 파일 자체를 `public/learning/persona-test/analyst.html`로 그대로 옮길 수 있는 소스 구조다. 실제 복사·사이트 수정·게시·통합 렌더는 하지 않았다.
- 원장의3개년 수치, 매출 구성합120, 분기합120, 현금20+9−6−3+0=20, 비율·증감·고객 비중, 단순 잔여3, 동결 가정14, 인당 단순 평균0.75를 확인했다. 모든 문장의 회계 해석을 독립 검수한 것은 아니다.
- 매출 막대 폭100/70/30%가60/42/18억원에 비례함을 소스에서 확인했다. 화면상의 실제 pixel 폭을 측정한 것은 아니다.
- 태그를 제외하고 공백을 축약한 페이지별 문자 수는893/1003/886/1068자였다. 이는 빈 페이지가 아니라는 보조 기록이며 밀도·가독성 합격 기준이 아니다.
- `overflow:hidden`으로 넘침을 감추지 않는다. 실제 넘침 여부, PDF 페이지 수, 인쇄 여백, font fallback 결과는 미검증이다.

내부 데이터 파일을 읽어 ID·치수를 직접 조회한 것은 일반 UI 독자보다 유리한 조건이다. 메뉴 탐색 성공, 소요 시간, 클릭 수, 이해 속도, 실제 사람 테스트는 측정하지 않았다. 이미지 관찰1쪽을 보고서 렌더 검증으로 세지 않는다.

## 사소한 QA 정정 이력

1. `report.html` 1쪽의 `자체 계산입니다。`를 **`자체 계산입니다.`**로 정정했다. 총괄 지적 전에 적용됐으며, 총괄 요청에 따라 이력에 명시했다. 의미·산식·배치 변경은 없다.
2. 초안2쪽의 `棒 길이는`을 `막대 길이는`으로 정정했다. 총괄의 본문 동결 요청 이전에 적용한 표기 수정이다.
3. `decisions.json` 작성 중 남은 한자 표현3곳을 `기존`, `전년도 사업별 구성`, `성장`으로 정정했다. 보고서 내용의 추가 개선은 아니다.
4. 첫 검사에서 정규식이 `data-grid-id`와 `data-chart-id`까지 HTML `id`로 읽어 중복 검사에 실패했다. 검사식만 공백 뒤 `id`를 찾도록 고쳐 재실행했고 실제 ID10개는 중복이 없었다. 이 실패를 보고서 버그나 렌더 실패로 보고하지 않는다.

## 인계와 남은 차단 사항

소유 범위에 따라 analyst 폴더의 세 파일만 작성했다. TEAM.md·STATE.md·public/UI·다른 persona는 수정하지 않았다. 공유 STATE 갱신 대신 총괄이 가져갈 완료/미완료 기록을 이 파일에 남긴다.

완료: 실제4쪽 원고·조판 소스, 선택/가정 기록, source-only 검사, 마침표 정정 이력. 미완료: 브라우저 렌더, 정확한4쪽 PDF, 출력·독자 시험, 독립 QC 결과 반영, Bishop 채택. 이 담당은 제한을 우회하거나 네트워크·브라우저를 재시도하지 않았다.

가장 큰 차단 사항은 **실제 렌더와 폰트별 넘침 검증 불가**, **채용 시점·역할별 비용·월별 자금계획 및 계약 근거 미제공**이다. 후자는 테스트 원장의 의도된 결측이며 추정 사실로 채우지 않았다. 독립 QC 중인 본문은 이번 제출 상태로 유지하며 추가 수정은 검수 결과와 사용자 지시에 따른다.
