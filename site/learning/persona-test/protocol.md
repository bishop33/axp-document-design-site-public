# 보고서 제작 페르소나 테스트 v1

## 목적과 범위
사용자가 현재 라이브러리 전체(기본 가이드, 그리드, 차트, 예시, 레퍼런스, 학습 기록)를 보고 품질 있는 문서를 만들 수 있는지 검사한다. 동일 모델의 독립 에이전트가 서로 다른 제작 조건을 모사한다. 실제 사람 실험, 모델간 벤치마크, 인쇄 품질 인증이 아니다. 최종 판단은 Bishop 검토 대상이다.

## 공통 과제
가상 기업 '가온 데이터 서비스'의 2025 경영성과 보고서, 한국어 A4 세로 정독용 4쪽. 독자는 이사회. 다음 연도 채용 확대안을 바로 승인할 수 있는지 판단한다. 아래 제공 원장만 사실로 쓰며 허위 고객·외부시장 수치·추천사를 만들지 않는다. 각 쪽은 주장-근거-해석-한계가 연결되어야 한다. 별도 표지로 한 쪽을 소모하지 않는다.

### 공통 데이터 원장 (모두 테스트용 가상 수치)
- 금액 단위: 억원. 기간: 각 연도 1~12월. 실적은 외부 감사된 사실이 아닌 시뮬레이션 입력값.
- 2023/2024/2025 매출: 80/100/120. 영업이익: 8/12/15. 영업현금흐름: 6/10/9.
- 2025 매출 구성: 구독60, 구축42, 유지보수18. 합계120. 전년도 구성은 미제공.
- 2025 분기별 매출: 25/28/31/36. 합계120.
- 2025 기초현금20 + 영업현금9 - 설비투자6 - 배당3 = 기말현금20. 기타 현금흐름0으로 단순화한 가상 모형.
- 2025 상위5개 고객 매출48(총매출120의40%). 고객별 금액, 계약기간, 갱신율 미제공.
- 2026 요청: 8명 추가 채용, 연간 총 추가 현금지출6. 채용 시점, 역할별 비용, 추가매출, 수주 확도는 미제공. 다른 조건 고정 시 2025 영업현금9 대비6 지출은 단순 잔여3이나 이것을2026 전망·순현금으로 단정 금지.
- 판단: 승인/조건부/보류 중 선택 가능하나 제공 데이터와 부족한 근거를 밝힌다. 시장 전망이나 ROI를 임의 확정하지 않는다.

## 사용할 자료
axp-document-design-site/public/guide/{topics.js,grid-systems.json,chart-catalog.js,examples.json}, public/references/catalog.json, public/learning/content.json, 실제 로컬 references/assets 이미지를 근거로 한다. UI를 직접 조작하지 않았으면 메뉴 탐색 성공·시간·클릭 수를 측정한 척하지 않는다. 내부 구현 소스를 읽는 것은 실제 일반 독자보다 유리한 조건이라는 한계를 적는다. 기존 제작 스크립트를 자동 실행해 완성품을 가져오지 않는다.

## 페르소나
1. analyst: 비디자이너 경영기획 담당자. Excel 수치 해석 가능, 편집 디자인 초급. 현재 공개 설명만으로 선택할 수 있는 것과 전문가 도움 필요한 것 구분.
2. designer: 편집 디자이너. 조판 경험은 있으나 재무 전문성은 없음. 보충한 디자인 결정은 개인 전문지식으로 표기하며 가이드 성과로 돌리지 않음.
3. llm: 명시된 규칙 중심의 문서 생성 에이전트. 미정 token·예외·계약을 추출. 추정값을 문서화하고 선언하지 않은 자동 최적화 금지.

## 제출 및 검증
각 담당은 자기 폴더만 수정: report.html(오프라인 열리는 실제4쪽 조판 초안, 외부 의존 없음), findings.md(읽은 근거 경로/ID, 단계별 결정, 스스로 보충한 값, 막힌 지점, 수용 기준), decisions.json(페르소나, 실제 선택 grid IDs/chart IDs/reference IDs, 페이지별 질문, assumedRules 배열). 차트는 단순 HTML/CSS 막대 또는 원자료표를 쓸 수 있고 모든 수치를 라벨링한다. 3연도 추세/2025구성/현금/채용결정 포함. 4쪽 모두 내용을 작성한다. 이미지가 없다고 가짜 레퍼런스 생성 금지. 테스트 결과물은 승인 예시가 아니다.

총괄 검사는 원장 보존, 합계·산식,4쪽,정의·누락표기,구조·가독성의 관찰 범위를 구분한다. 렌더 검증이 막히면 구조적 검사만 보고한다. 자의적인 점수로 품질이 입증되었다고 하지 않는다. 발견은 P1/P2, 재현 근거, 제작자 영향, 보완안, 재테스트 통과조건으로 기록한다.

## 레퍼런스 확장
신규 외부 접속은 승인서비스 장애 상태. 우회 금지. 보유 NBIM 원본의 다른 역할 내지를 보강하는 작업은 가능하나 신규 문서 수로 집계하지 않는다. 후보 링크 추가와 실제 이미지 확보를 구분한다.
